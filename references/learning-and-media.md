# 学习与媒体设计规则

## 内容完整性

先确定课程范围，再拆目标。一节课可以围绕一个主问题，但目标可能包含结构、机制、计算、解释与应用。为每个必需目标建立来源和任务映射，避免只实现开场与最后一道题。

用户未提供教材时，将目标集标为设计建议。用户给出完整原课时，注明保留、改编和移至拓展的内容；移出原课必需知识点会改变课程范围，须明确说明依据。

不要用年龄代替先修知识。课程入口说明需要哪些基础；按需提供术语卡、示意、例题或操作示范，主线不承担从零解释全部知识的义务。

知识单元、关系、诊断和教学顺序按[知识组织](knowledge-organization.md)制定；整任务、示范决策、指导程度、帮助撤除、表达反思、表征、检索与间隔按[教学设计方法](instructional-design.md)选择。先写关系与独立证据，再把它们放进课堂事件。概念图和故事连贯分别检查，不能相互代替。

## 课堂行为

所有课程在首次教学场景前或场景内设计背景引入：必要背景、已有认识连接、问题与动机、首个行动及自然衔接。写出实际画面和台词，不以标题、欢迎语或突然派任务代替。开场理解单独检查，不默认计为知识掌握。

| 环节 | 学生行为 | 设计要求 |
|---|---|---|
| 接受任务 | 理解角色，作初步预测或选择不确定 | 预测用于了解初始理解，预测错误仍能继续 |
| 宏观观察 | 建立整体、位置、关系和背景 | 只在空间有教学价值时使用 360°图片 |
| 局部探究 | 检查对象、证据和前后状态 | 当前问题与返回入口始终明确 |
| 操作判断 | 测量、变量、排列、构建、比较或解释 | 学生行动影响可理解的结果 |
| 反馈补救 | 对照证据，修正结果，实际再做 | 提示指向具体错误，允许重试 |
| 新情境应用 | 换数据、对象或条件完成相同知识目标 | 首次尝试和求助后结果分别记录 |
| 回顾结课 | 查看学习证据和待练目标 | 课程完成与独立理解分别表达 |

角色要承担知识任务。例如测量员处理变化率、调查员比较资料、运输观察员追踪膜融合。同伴问候、现场声与行走镜头建立参与感后，需要带来行动机会。

第一人称允许人物持续引导、协同和接话。人物有当前目标与可见行动，镜头跟随视线和动线；知识旁白不使用第二人称行程解说。写出互动的实际内容与对应回应，不只在剧情旁边增加题目。参见 [剧情与交互编排](drama-and-interaction.md)。

默认主线教学逻辑固定，场景中可自由检查不同对象；首次界面隐藏未来节点、完整路线和步骤编号。当前主媒体或场景对象的事件逐步提出下一问题，当前动作保持明确；原生空间课不强加视频。全课完成后才提供自选节点回顾。拓展发现可以略过，关键证据通过指引可获得。避免强制点击所有热区作为学会的条件。

## 媒体分工

对应的图、文字、声音与动作尽量在同一对象和相近时间出现；突出当前关系，删去与目标无关的装饰，复杂内容允许暂停、分段和回看。上述原则不能用于删除字幕、静音等价文本、术语拼写或无障碍支持；沉浸式媒体的具体效果仍需实际试学。[LS17]

### 视频推进

用视频引出事件、改变情境、提出任务和承接结果。每段写明进入前的课堂状态、段内变化、学生接下来做什么。人物回头示意、机器启动或环境改变要服务这一变化。

分镜写明人物、场景、镜头起止、动作、动线、对白、画外声、知识旁白和声音。每处交互明确哪个事件开放什么对象、实际展示什么内容、学生怎样操作、反馈如何改变人物或物件，以及返回哪个镜头。

操作时暂停或停在清晰观察帧。视频到结尾仍未点击时，保持有效入口；无缝循环必须单独验收。长课由多个推进片段、讲解和操作共同构成。

旁白须有实际音频，与事件、字幕和热区同步；可配合模型、图形和宏观图延续。进入局部暂停主线声音，返回恢复，静音保留全部字幕。讲解长度不受单次视频生成时长决定。

### 360°图片承担宏观叙事

选择能帮助建立全局的特殊场景：工厂与城市关系、历史地理、生态环境、身体总体、细胞空间、工程现场等。

写清整体关系、主要观察方向、旁白段落、局部入口和退出条件。旁白与高亮可按段切换，静态图片中的事件进展用视频或规则动画表示。

保存进入局部前的观察方向，返回后恢复。提供可选定位按钮与文字目录，学生不需要持续转动寻找主线入口。宏观到局部保持名称、图例和关系一致。

全景比例或提示词中出现“360°”不等于投影正确。验收实际投影、接缝、极区、地平线、尺度和区域方向。必要时采用可验证的全景摄影、渲染或空间重建路径。

### 局部 3D 与视频热区

3D 用于内部结构、路线、旋转、切面、分步状态和变量操作。以 Blender 制作达到近景要求的资产，浏览器加载GLB交互；提供复位与总览。结构、材质、灯光和动画均需验收，结构示意与真实比例的区别用适当标识说明。

视频热区用于现场物件、人物、仪表、文书与具体动作。记录时间和目标轨迹，遮挡时停用。任务在同一场景舞台内完成，不放在独立页面卡列里。打开对象或模型后暂停主线与声音，关闭后回到原时间和视角，显式继续。

空间热区和视频画面热区采用各自坐标。不能把两种标注直接互换。

精确数量、公式和数据在教具中呈现，不从生成画面估算。高精度图形、SVG、流程图和表格也可以承担局部任务，按知识需要选择。

## 跨学科适配

| 知识类型 | 合适的学生动作 | 必须固定的依据 | 可用的结课任务 |
|---|---|---|---|
| 数量与关系 | 测量、计算、改变参数、诊断错误 | 单位、范围、公式和数值 | 新数据计算并解释结果 |
| 结构与空间 | 定位、旋转、切面、关联局部与整体 | 结构、尺度说明、连接关系 | 新视角识别或重建关系 |
| 时间与流程 | 排序、追踪、暂停、比较受阻状态 | 步骤、方向与条件 | 判断流程变化的结果 |
| 科学机制 | 控制变量、预测、运行、解释 | 模型假设、作用规则、适用范围 | 换条件作预测并说明边界 |
| 史料与因果 | 查资料、比较来源、关联证据与主张 | 来源、时空范围与论据 | 新材料形成有依据的解释 |
| 语言与表达 | 场景对话、选择表达、修改和说明 | 表达目标、语境与评价要点 | 新情境完成沟通任务 |
| 技能与创作 | 尝试、比较示范、修订作品 | 步骤、约束与作品评价要点 | 完成新的作品或操作 |

科学、历史和语言类示例不会覆盖所有学科。根据内容补充评价要点，不为新学科强套既有场景。

## 反馈与补救

把错误分成操作困难、结果错误和解释不足。操作困难先解决控件使用；结果错误指向变量、结构或证据；解释不足指出缺失的因果环节。

按[课程评价](course-evaluation.md)的形成性闭环解释答案，记录其他可能原因及下一教学动作。一次错误不能确定误解；正确结果但依据错误时仍需关系补救。增加诊断只为解决实际不确定性，不把每次观察变成测验。

建议提示逐步提供：指向对象 → 提示关系 → 展示一步 → 必要时完整示范。使用完整示范后，学生仍需完成对应操作；后续独立任务重新检查理解。

不要因固定答错次数阻断课程，也不自动编造扣分、通关分数或时间限制。用户需要评分时，根据已确认的规则制定。

开放解释使用评价要点。历史主张允许多种合理组织，语言与作品允许多种表达。首版可采用结构化依据选择、排序与证据关联检查必要要点；自由文本可供审阅，不声称已实现可靠自动评分。

## 完成与理解

评价从目标阶段开始：先写核心能力、成功标准、预期困难和新任务，再反推讲解、练习与媒体。每项互动注明核心推理、取证、引导、操作支持或独立评价，检查学生思考、证据、反馈、删减损失与注意力成本。

课程完成要求必需任务已完成教学过程、新情境任务已尝试且反馈已查看。结果页显示各目标的独立完成、辅助完成、仍需练习或尚未尝试。

没有辅助的正确结果仍需满足任务的解释要求。得到教学帮助之后，在新情境中的独立表现单独记录。点击量、观看时长与完成率描述参与行为，理解需要任务证据。

若要证明学习提升，用相同目标的可比较评测和清晰的实验条件。少量 Demo 试学可发现问题，不能据此承诺学习收益。
课程效果与单项互动贡献分别评价；记录实际版本、条件、分母和缺失，不把完成率、点击或满意度代替依据、推理和迁移表现。
