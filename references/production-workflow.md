# 制作、运行与验收

## 阶段与产物

| 阶段 | 工作与产物 | 进入下一阶段的依据 |
|---|---|---|
| 内容核对 | 原课版本、知识点、题目、来源与教具清单；提供/继承媒体执行[输入实检](source-media-admission.md) | 必需范围与资源状态明确，依赖输入已实际审阅 |
| 目标映射 | 教学、检查、补救与迁移映射 | 每个必需目标都有完整路径 |
| 贯穿评价 | 核心能力、成功标准、误解、互动价值、证据与试学方案 | 任务要求目标能力，辅助与掌握分开 |
| 开场引入 | 课程主题/用途、整体背景、对象术语、已有认识、问题、角色关系及呈现事件 | 所有课程与独立小样在首个学科任务前提供必要背景；继承与恢复有本地回顾及失败回退 |
| 课堂编排 | 人物目标、场景变化、动作动线、对白、宏观观察与局部操作 | 课堂连贯，行动有教学作用，人物能引导与回应 |
| 素材设计 | 逐镜头首尾、空间布局、实际台词、交互触发与内容、模型规则和声音 | 关键对象可辨认，媒体适合任务，反馈与返回可制作 |
| 设计确认 | 交付完整课程设计MD，标明版本与待确认状态 | 用户明确确认当前版本后才能制作和实施 |
| 关键小样 | 最难且有代表性的“主媒体→操作→反馈→返回”完整闭环 | 正式候选质量支持指定行动、声音、连续性、移动端与等价路径 |
| 小样确认 | 交付小样证据、风险与批量生产契约 | 用户明确确认当前小样后才能批量生产 |
| 全量制作 | 视频、图片、教具、资料、字幕与音频 | 内容和质量可用，来源版本完整 |
| 标注组装 | 热区、任务、反馈、补救、转场与记录 | 能进入、完成和退出每个必需节点 |
| 学习验收 | 正常、错误、求助、重试、回看与恢复 | 无学习死路，结果记录符合规则 |
| 试学修订 | 操作障碍、错误类型与迁移表现 | 主要学习障碍已修正 |
| 交付固定 | 课程入口、内容包、媒体、规则与验收 | 同一版本能够复现体验 |

设计确认和最难代表性媒体闭环确认是固定的两道人类确认门；其他检查是内部质量关口，不重复要求审批。媒体闭环确认后在已授权范围内完成可逆的全量生产。发布、付费制作或外部写入按实际授权处理。

## 素材生产

全流程执行 [媒体、角色与互动连续性](media-interaction-continuity.md)。设计、制作、组装与准出逐场保留同一事件、角色、对象和行动链；存在角色对话或引导的360°/3D场景须制作与场景匹配的实体及参与，声音、姓名和头像不能代替在场。

设计人工确认后，先按[生产级 Beat 规格](beat-production-specification.md)把课程事件拆成生产卡，再查实际工具可用性与当前能力。普通图片生成只使用 TRAE `GenerateImage` 或 Codex `Image gen`；视频生成只使用 TRAE `GenerateVideo`。按“普通图片、视频、声音、3D、全景、浏览器运行时”登记能力；当前工作区默认值读取[项目生产配置](project-production-profile.md)。工具不可用时停在 `design_draft` 或 `prototype`，不静默替换未批准的提供方。浏览器负责加载正式成品，不能用粗糙程序几何降级。

3D资产按[3D生产方法](three-dimensional-production.md)选择整图或主体分割后的透明切图输入。可复用Atlas调研的纹理GLB生成与任务历史，实际生成后须在Blender检查和整理结构、独立部件、枢轴、材质与动画；精确机构可直接建模或重建关键连接。保存原图、mask、cutout、实际参数、每次尝试、GLB、纹理、可编辑.blend及校验值，再接入网页验收。生成任务成功不能直接标记教学可用。

视频先执行[通用生产系统](video-production-system.md)：从生产级 Beat 规格生成 shot list，建立实测环境与能力矩阵，拆解来源并锁角色/场景/道具参考包；按最终录音或原生对白实测确定声音时间轴，再编译实际镜头与独立生成单元。通过 TRAE `GenerateVideo` 生成正式候选 MP4，并登记真实输出路径、提示词、参数、参考素材和返回结果；SVG/FFmpeg motion 只可作为明确标注的原型或离线等价资源，不得冒充视频生成结果。来源、计划、可提交和返回时长分开，完整台词不裁切；一个单元覆盖多 shot 时只装配相应源区间一次。
导演、表演、物理动作、光照和首尾接缝按[导演与连续性](video-direction-and-continuity.md)逐项设计，不以固定镜头数、情绪焦段或“电影感”后缀代替。对象与真实动作决定画面覆盖，等待帧留在说完且动作到位之后。

视频生成与声音处理以[课程视频生成与故障规避](video-generation.md)为唯一决策来源。正确原生对白保留；错误对白重生成或由最终声线驱动口型，旁白与已建立同场位置的画外反馈可另配。正式线性视频须自带完整声音。写实风格、输入能力与隐私错误按该模块的实际条件处理。
成片按[时间线与实际验收](video-timeline-and-quality.md)运行视频计划/实际文件校验，保存源片范围、单元装配、声音事件、冻结候选与逐句听审。不用静帧补时、循环或数码缩放掩盖真人说话/行动缺口；静态教具与互动等待登记具体用途。完整全课核对全部必需视频及主要分支，不能由一条小样通过推断全课通过。

第一人称保持学习者视点与人物视线，物件和局部转换有镜头衔接。互动镜头分别预留动作到位、说完话、稳定等待、分支回应和离开的剪辑点；同一分支的进入与退出位置、持物和光线一致。实际对白、画外声和知识旁白分轨管理，旁白不复述学习者行程。

语言和配音引擎由项目配置或用户要求决定。每种语言都为角色选择固定声线并为旁白使用独立声线；媒体计划登记参考、校验值和模型版本，开场、主视频及互动分支沿用同一参考。当前工作区普通话流程按 `references/voice-continuity.md` 执行。检查视频自带旧人声、术语发音、跨段音色、混音和开口时序；多角色按各自提供的证据与回应参与课堂。

参考图遭拒绝时记录实际返回，检查可调整素材或文字生成路径，重验连续性。不能把请求提交、生成成功和素材教学可用当成同一个状态。

教学任务从当前事件或对象进入，并在同一学习工作面完成；入口可为视频热区、全景对象、图表对象或资料工作面，按实际媒体适用。旁白与反馈、字幕和媒体事件共用时序。科学反馈来自规则，历史数据来自资料；生成媒体不决定实验结果和史实。

全景小样须验证实际投影。单图生成可用性不足时，采用受支持的多视角、拼接、三维渲染或真实全景路径，并重新检查空间一致性。替代方案保持宏观叙事的教学目标，说明实际环视能力。

每项素材记录：

- 稳定标识、关联节点、教学作用与关键对象。
- 原始来源或生成工具、实际可知的模型信息、提示词与参考素材。
- 分辨率、投影、时长、编码、版本与实际文件。
- 制作状态、验收结论、问题、替换方案与重做记录。
- 实际消耗或可获得的计费记录；费用未知时写未知，不猜个人余额。

工具未返回的版本和参数不作推断。首尾循环、放大与插帧分别验收，不用输出尺寸证明细节或运动质量。
异步任务、下载恢复、取消、预算与共享GPU按[媒体任务运行与恢复](media-job-execution.md)执行。

## 浏览器运行

将媒体播放、宏观场景、局部教具、任务反馈和进度拆成可复用模块。课内容提供目标、任务和规则，框架负责呈现与状态。

Vite + TypeScript 可承载播放器、资料、题目和记录；Three.js 用于空间观察和模型操作。框架是实现选项，教学蓝图保持可迁移。

| 行为 | 运行要求 |
|---|---|
| 打开局部任务 | 暂停冲突的媒体和旁白，保留当前任务 |
| 关闭面板 | 回到正确画面或观察方向，提供继续入口 |
| 缩放与换屏 | 视频与热区使用相同布局，3D 单独命中 |
| 返回已完成场景 | 保留完成进度，允许独立重做任务 |
| 中断恢复 | 恢复当前节点、证据和已提交结果；音频通过用户操作恢复 |
| 主动等价路线 | 操作者显式选择已验收路线；按该路线自身资源准入与目标推进 |
| 必需媒体失败 | 重试、重新加载或重新进入；持续失败阻断，不自动切换体验 |
| 静音与操作替代 | 字幕保留主线；鼠标、触摸或键盘能完成主要动作 |
| 叙事与节点 | 首次隐藏未来节点与完整路线；结课后由学生选择是否显示节点回顾 |
| 任务与声音 | 热区在画面内进入任务，保持现场；暂停、模型切换、恢复后旁白与字幕同步 |
| 结果页 | 展示完成状态、各目标表现和相关回看入口 |

首次原型可以使用本地进度；正式接入账号前核对接口。只承诺实际测试的设备、浏览器与恢复范围。

原型实现先按[前端与原型设计契约](frontend-prototype-contract.md)固定技术、运行时区域、tokens和状态，并按[课程成品UI与布局](final-page-ui-quality.md)保存本课 `page-design.md`。布局由实际对象、资料与操作决定；子工具静态阶段返回后，本课程编排器接回并执行已授权的浏览器验收，用户只要静态示意时按该范围结束。功能路径运行后进行成品打磨；全课组装后使用正式素材复查排版、自然文案、状态、缩放与手机构图。旧版实测保留版本或哈希，不能作为新交互已通过的依据。

## 版本关联

接续制作只加载当前阶段与媒介所需 owner。工作记录保存当前范围/版本、已完成产物及证据、部分进度、未完成项和原 Job ID；从最早失效的依赖恢复，不把部分完成写成阶段完成。换课程、分支或范围先核对身份与指纹，正式状态继续以生产清单和既有流程 owner 为准。

可选制作侧 observer 从这些记录派生进度、耗时和成本展示，其故障可以降级为无面板；必需 Job、输入准入、版本或验收记录写入失败仍须阻断相关推进。observer 不拥有正式状态，也不进入学生视频主舞台。

素材标识与节点标识保持稳定。更新视频时重查时间热区和字幕，更新全景时重查方向与局部入口，更新模型规则时重查题目、解释与正确结果。

按[生产清单契约](production-manifest.md)分开保存总包版本、确认范围版本及实际内容指纹。教学内容或制作约定变化只让受影响范围的确认失效；同约定下重做其他素材只重新验收该素材与实际接续。已确认小样及其依赖变化必须重确认。非语义错字/排版保存差异核对记录，不用重算并覆盖旧确认指纹。

保存课程版本与任务尝试时的版本。换版本时若进度无法安全恢复，显示明确的重学入口，不把旧答案错误套到新任务。

## 验收

| 范围 | 通过条件 |
|---|---|
| 内容覆盖 | 每个必需目标有呈现、练习、补救与结课检查，来源可追溯 |
| 主线 | 学生知道当前问题；每个必需节点能到达结课 |
| 开场 | 清空进度后主题、对象含义、动机和首动作可理解；信息到实际镜头/字幕/页面事件一致；各分支先引入再开任务，静音/失败/恢复均成立；结构、内容审阅与真实试学分开 |
| 互动价值 | 学生实际使用目标知识，答案与反馈暴露困难，核心思考未被次要操作挤占 |
| 情境设计与操作负担准出 | 载体和氛围符合课程对象；核心交互产生可观察状态、反馈和现场接续；当前选项简短且通常2—3个，完整资料可访问，触摸/键盘/窄屏实测可操作；长菜单堆叠或只有装饰变化先修复 |
| 剧情与互动 | 镜头、人物目标、动作和对白连贯；触发、内容、操作、结果与人物回应一致 |
| 媒体分工 | 视频推动阶段，全景建立整体，局部互动支持具体学习动作 |
| 媒体与互动连续性准出 | 视频、360°、3D与操作围绕同一事件；说话/引导角色有现场实体和相关参与，环视可定位、窄屏可见，结果回到人物/对象，媒体转换与恢复不断链；任一必需场景或主要反馈分支割裂、真空对话均阻断准出 |
| 画面与声音 | 关键对象清楚，连续性合理，字幕可读，音频可控 |
| 全景 | 投影、接缝、地平线与区域入口正确，环视能力描述真实 |
| 教具 | 数值、结构、路线与变量结果符合规则和内容 |
| 热区 | 时间、运动、遮挡、暂停、跳播、缩放和换屏后表现正确 |
| 有声叙事 | 主线与主要反馈有实际音频，字幕一致；环境声不盖人声，媒体转换不重叠 |
| 配音连续性 | 符合项目/单课教学语言及发音约定；角色固定参考，旁白独立；原声对照与生成状态明确，跨段试听和口型已验收 |
| 资产品质 | Blender结构、材质、光照、动画和导出表现达到近景要求，机构无穿插脱节 |
| 图生3D生产记录 | 输入主体和透明边界正确，结构依据、部件与枢轴、纹理GLB/Blender源文件、版本与尝试可追溯；生成、整理与浏览器可用分开验收 |
| 探索界面 | 首次不泄露未来节点；任务在场景内；结课节点回顾默认关闭且可自选 |
| 成品UI与布局 | 本课视觉方向与内容布局明确；真实资料、教具、字幕和主动作可读且无遮挡，中文文案具体；长内容、手机、缩放、焦点和边界实测，组装后打磨有本版截图与操作证据，结构检查不替代页面品质 |
| 补救 | 每类主要错误有相关反馈，重试后能够继续 |
| 记录 | 首次、辅助和迁移结果分别记录，课程完成不冒充掌握 |
| 恢复 | 退出、刷新与回看不会丢失已提交的主要进度 |
| 试学 | 记录具体障碍和错误，修复影响主要学习任务的问题 |

结构脚本只能覆盖引用、目标映射、反馈和路径。源内容、媒体质量、开放解释和真实浏览器运行仍需验收。报告实际运行过的检查，不把计划勾成完成。

按评价方案记录设计评审、试学观察和独立新任务表现。需要评估学习变化或互动贡献时使用可比任务与条件，报告实际样本、版本和不确定性；未评估的学习效果不能因运行通过而写为通过。

## 复用

通用层保存节点、媒体、任务、反馈与记录能力；学科层保存公式、机制、路线、史料和评价规则；课程层保存具体来源、剧情、素材与任务。

复用时先重新建立目标映射，逐项确认适用规则。替换学科不能只换标题、贴图和对白。
