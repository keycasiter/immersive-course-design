# 视频场景中的学习参与设计

用于 `video_led_web` 新课和受影响交互的重大改稿。先完成本模块，再写控件和页面。其他课型可借用目标到动作的推导方法，不继承视频运行规则。以下为课程设计与验收约束，不是经过本课试学验证的教学效果结论。

## 从目标推导现场行动

先按 `narrative-scale-and-perspective.md` 确定本课叙事尺度与参与范围。这里的“现场对象”既可为信件/仪器，也可为当前事件的地图、时间关系、多方证据或系统模型。叙事全程宏观时可直接操作整体关系，不必把每次交互改成局部人物或物件场景；深层视图只是交互层级，不能自动当成叙事尺度切换。

逐个视频事件回答以下问题，形成 `scene-interaction-plan.json`；没有互动的观察事件也登记，避免为补数量制造热区。

1. **要看懂什么**：将目标写成可观察表现，指出当前缺少的关系或证据。不能用“增强沉浸感”“增加互动”作目标。
2. **现场有什么可用**：确定画内对象、当前变化、可辨认入口，以及学习者已经获得的背景。先看视频能否充分呈现；能呈现且无需作答时保留观察事件。
3. **学习者要做什么**：写一个有知识含义的动作，如比较高度、选择支持主张的原句、预测后调节变量、剖切后说明连接关系。点热区只是进入方式，旋转、拖动或点选本身通常不能证明理解。
4. **使用什么表面**：先考虑贴近对象的直接控件；需要细看、阅读、对照或操作空间时进入同一对象的深层场景；短问答或必要帮助才使用场景卡。记录更简单表征是否能支持相同动作和证据。
5. **行动前必须知道什么**：从当前任务反推最小信息集，分配到实际画面、对象、已播放内容或控件标签；首次使用的对象和操作必须能理解。不得以减字隐藏判断必需的条件。
6. **怎样看见结果**：分开写操作后的对象变化、知识反馈、主要误解的修订入口和现场接续。按钮变色只能表示选中状态。
7. **怎样完成和返回**：分别定义探索退出、练习完成、独立提交和掌握证据，写出精确恢复状态与等价操作。

上下文足够时由 Agent 给出推荐方案和依据。只有学习者条件、目标或权限等不可发现信息会实质改变选择时才向用户提问；不要求用户逐场替设计者选择控件。

`video_led_web` 的核心入口必须来自当前帧可辨认的对象、主引导 NPC 的动作或交接、声音线索或事件热区。交互不是独立模块入口；完成后由对象变化、NPC回应或下一段短视频承接，再精确回到主线。默认采用局部分支后回归，分支至少改变一个可见状态、角色回应、证据集合或后续条件；只替换正确/错误文案不算故事分支。

## 三种表面及选择边界

| 表面 | 适用动作 | 必须保留的内容 | 需要改选的信号 |
|---|---|---|---|
| 视频内直接控件 `scene_control` | 指认、配对、测量、少量变量、两状态比较、选择问题或证据 | 可见作用对象、条件、控制结果、恢复位置 | 对象太小、需长文或多视角、操作遮挡证据 |
| 同对象深层场景 `object_inspection` / `document_reading` / `guided_experiment` / `deterministic_tool` / `simulation` / `spatial_360` / `spatial_3d` | 原文取证、资料对照、机制试验、结构剖切、空间观察 | 同一对象与事件、完整材料/规则、返回锚点、草稿 | 只为展示技术；简单图示和控件已能支持目标 |
| 场景辅助卡 `scene_card` | 简短判断、追问、当前提示、反馈或局部输入 | 一个当前问题、必要选项、当前反馈 | 同时塞入背景、资料全文、多个问题、量规和总结 |
| 保留视频 `video_only` | 看清或听懂变化，无需当前互动 | 观察目标、证据出现位置、必要解释 | 后续要求独立作答却没有获得所需证据 |

深层场景不限定为 3D。史料可以在画中信件的正面阅读视图中按原顺序翻阅、摘录和对照；数学可以在同一测量对象上显示确定性图形；语言课可以操作句子；实验可以使用规则驱动的二维仪器。阅读或写作本身是目标时，让材料或作品成为当前对象，提供足够空间和不限时停留。不能把长文转成大量语音、碎卡或无意义翻页来制造低阅读负担，也不能仅因文字较长强加 3D。

除表中表面外，可按知识动作使用时间轴回放与预测、地图/关系网、证据连线、部件组装、虚拟仪器、步骤演练、作品批注、角色对话、口语输入或声音辨识。它们仍须从当前场景对象进入、给出目标证据、产生可见后果并返回同一视频事件；不因技术新颖获得优先级。

“场景内”由对象入口、学习动作、状态接续与返回决定。深层阅读/实验可暂时占据舞台，清楚说明正在细看哪个对象，并保留返回。它不是独立资料库、课程目录或永久工作台。完整课程结束后的作品回顾按目标需要呈现。

## 把视频与可操控场景连接起来

把视频视为有时间和空间的现场底片。准确数值、位置关系、变量、命中区域和知识反馈由确定性控件、图形或仿真承担；生成视频中的仪表文字或物理变化不能充当可靠计算规则。

- **直接叠加**：在对象稳定时开放控件；移动对象使用时间对应的锚点/轨迹和遮挡规则。暂停后保留当前帧，控件贴近实际作用位置。
- **匹配进入**：由同一物件、视线或局部放大进入可操作视图。定义进入后的方向、尺度、对象状态和环境声，不让用户重新寻找目标。
- **整体参与**：在当前时空关系、事件或系统对象上比较、预测和组织解释，结果改变学习者的证据关系、模型或方案。需要跨时空/层级进入时显式定位并保留同一问题；历史判断不冒充改写真实事件，模型试验披露规则和边界。
- **反馈接续**：操作结果在对象、证据组织、确定性输出或角色回应中出现。允许固定主线加局部状态反馈；只有真正制作并验收过的分支视频才能声称人物/视频按选择改变。不得用叠加文字假称已改变视频里的物理世界。
- **精确返回**：恢复媒体时间、视点、对象、作答/草稿、焦点、声音、字幕和完成状态。默认接回暂停秒；使用预先设计的接续秒时写明被略过区间的用途，不跳过尚未呈现的教学证据。

视频时间是唯一教学时钟。必需事件到点暂停；可选探索入口在有效窗口出现，用户进入后暂停。阅读、比较、写作和试验时停止冲突的主线人声；保持有意义且不干扰的环境声。热区不强制命中正在移动的小目标，不限定答题时间。窄屏裁切、旋转或缩放后仍能定位同一对象。

## 信息分层与阅读负担

以当前行动所需的**意义单元**登记信息，不能只数汉字或卡片。一个单元表达一个条件、关系、操作或证据，不把整段内容算成“一项”来规避检查。

| 层 | 何时呈现 | 应包含什么 |
|---|---|---|
| 行动前 `before_action` | 在当前任务开放前或对象首次使用时 | 当前目标、未获得的必要条件、陌生对象/操作的最小说明 |
| 按需 `on_demand` | 学习者取用对象或请求帮助时 | 完整来源、术语、重看、当前步骤提示；需要取证的材料保持可发现 |
| 行动后 `after_action` | 操作/提交后 | 已发生的结果、针对性关系解释、修订入口；独立任务提交前不泄露答案 |

每事件记录首屏单元、局部上限及其依据。上限由任务复杂度、先修、设备、必要对照和小样观察决定；没有跨课程固定字数、选项数、热区数或每分钟配额。预算是风险提示，不证明阅读轻松。超过预算先查重复说明、是否能把对象直接呈现、支持能否按需展开；确需更多时调整预算并写理由，不缩小字体或删去关键事实。

资料须保留全文、顺序、数值、条件、来源和引用位置。可以导航到相关位置，不能提前高亮正确证据或用摘要替代以原文取证为目标的阅读。逐步揭示不增加无意义的点击。对照任务可以同时看到必要对象，但同一时刻只有一个主任务和至多一个辅助层；主任务可以包含自然连贯的预测、运行、比较步骤。

零背景入口继续覆盖地点/系统用途、行动身份、当前事务、对象与目标。用现场动作、入场提示、对象和按需支持分担；首个学科判断前必须实际呈现其必要背景。不得重新拼成 NPC 长简报，也不得以隐藏说明制造困惑。

## 动作到证据的选择表

| 知识动作 | 推荐起点 | 有效证据与反馈 | 常见误用 |
|---|---|---|---|
| 观察变化 | 视频观察；需指认时用定位控件 | 指出变化对象/时间/关系，返回对应画面解释 | 看完即算掌握、每镜头弹一道题 |
| 比较与测量 | 对象旁切换/标注/测量；必要时局部放大 | 对应值、单位、差异或关系；错误定位到比较基准 | 只点“相同/不同”，资料不足 |
| 原文取证 | 从信件/作品热区进入阅读，选取原句关联主张 | 引用位置及其与主张的联系；反馈针对证据适用性 | 自动标出答案、全文塞进问答卡 |
| 预测与试验 | 先保存预测，再用滑杆/按钮/数值输入运行仿真 | 条件、预测、结果与解释；显示确定性变化 | 拖到目标颜色即算理解 |
| 结构与空间关系 | 先检验二维图/定位控件；必要时 3D/360° | 部件、连接、方向及解释；剖切或视角变化 | 自由旋转打卡、必须使用头显 |
| 解释与创作 | 当前对象上的关联、批注或作品输入 | 作品、证据联系与边界；量规在独立提交后开放 | 用排列步骤代替推理、输入前泄露量规答案 |

上述为选择起点，不能把推荐表变成学科与媒体的固定对应。3D 结构若二维图能完成相同证据任务，则选二维。语言、历史同样可有真实操作，但物件搬运必须服务理解和证据组织。

## 完成、退出、帮助和恢复

- **观察**：指定证据已呈现可推动叙事；不记作学科掌握。
- **可选探索**：可随时返回，保留已查看或已操控状态；开关热区不作为完成证据。
- **引导练习**：按当前证据规则完成，可得到针对性反馈并修订；不能一律以选对为整课完成条件，也不能仅凭尝试次数放行。
- **独立任务**：先保存完整首次提交，再开放该任务的答案性反馈和量规；提交、待审与掌握分开。正常资料、工具和无障碍路径不自动算求助。
- **关闭必需交互**：允许收起或回看，保留草稿和待完成状态，视频仍停在当前未完成事件；关闭不能绕过证据门。
- **等价操作**：点击/触摸/键盘均能操作；拖拽、旋转、精细指认提供定位、选择或数值输入替代。保留相同判断与证据机会，记录使用了改变评价条件的提示。无障碍等价路径继续与必需资源失败的重试/阻断机制分开。

## 设计与实现检查

复制 `assets/scene-interaction-plan.template.json`。逐事件填写实际内容，使用与视频事件表一致的 Beat ID、交互 ID 与顺序。完整课填 `coverage_scope=full_course`；明确局部修订填 `selected_events`，只能声称覆盖所列事件。运行：

```bash
python3 "<skill-root>/scripts/validate_scene_interaction_plan.py" \
  "<course-directory>/scene-interaction-plan.json"
# 有正式事件表后，检查全部关联或已声明的局部范围：
python3 "<skill-root>/scripts/validate_scene_interaction_plan.py" \
  "<course-directory>/scene-interaction-plan.json" \
  --event-map "<course-directory>/video-event-map.json"
```

结构校验检查覆盖、分层、表面决策、暂停、证据与返回字段的一致性；不能判定原文选择是否合理、剧情自然或负担是否合适。`page-design.md` 给出实际控件及最长必要材料的桌面/手机状态，`verification.md` 单列内容审阅与浏览器结果。

实际检查：无额外说明能找到当前对象和动作；入口来自当前帧对象、NPC动作、声音或事件；必需条件可获得；首屏不堆背景与多任务；对象/知识反馈可辨；帮助不提前泄题；分支有对象、角色或后续条件的真实变化；关闭必需任务不能放行；退出、重进、刷新和键盘焦点保持同一状态。学习者可见文案按 `experience-framing-and-learner-language.md` 使用情境语言，不展示内部核查、证据、待审或目标状态。资源失败仍按原准入契约重试或阻断，不新增第三道确认门。

跨学科检验至少覆盖不同动作与表面：史料取证的原文完整性、变量实验的确定性结果、结构检查的二维/3D选择、语言作品的首次独立提交，以及无需互动的观察段。合成样例仅为方法与结构检查，不是课程确认、真实试学或效果证据。
