# 从目标与证据选择教学方法

在知识组织完成后，随完整脚本持续执行。本节提供决策方法；具体课堂内容仍按颗粒度标准写全。研究依据及适用边界见[学习科学依据](learning-science-evidence.md)。

## 逆向设计与教学对齐

依次决定目标、可接受证据、教学与练习，并允许来回修订。[LS2、LS3]

对每个必需目标写一条可核对链：

`学习者条件 → 知识关系 → 独立表现与成功标准 → 所需证据 → 教学／示范 → 引导练习 → 撤除帮助 → 独立任务`

目标写成“在什么材料或条件下，做什么，做到什么程度”。“理解因果”改成“比较给定史料，对一个主张选择有效依据、解释联系并说明限制”。动词本身不决定任务难度：选项题可以要求推理，开放题也可能只需抄写。

Bloom 的修订分类或 SOLO 可辅助审视认知要求，不能作为六级必经流程、配题比例或自动评分标准。优先检查任务实际要求与目标一致；需要使用分类时查原始定义，不只查动词表。

逐项检查：

- 目标要求解释，教学和练习是否真的教、练了关系与解释？
- 最后题是否意外增加未教概念、阅读、计算或工具负担？
- 完成操作是否足以提供证据，还是必须补理由、条件或结果？
- 开放任务是否保留合理答案，量规是否误奖与目标无关的文风、长度或角色表演？

沉浸场景是知识与行动的载体；它的真实性、情绪强度或视听质量不能替代这条链。

## 任务深度检查

进入互动规格前，逐项核对“目标中的关系/条件 → 学生实际判断 → 所用材料 → 成功依据 → 误判反馈 → 新材料独立应用”。目标要求解释、机制或迁移时，仅复述人物说了什么、选择剧情先后或抄回原句不足以通过。

按材料和目标选择比较、删改后果、条件变化、反例、预测、证据联系或解释边界。题型和开放输入本身不保证深度；选项也须迫使学习者使用目标关系。适用时将证据支持的结论与尚不能推出的结论并列核对，保留合理不同解释。

用两个问题审阅每项任务：

1. 不检查目标关系，只凭情节记忆、措辞重复或界面暗示能否答对？若能且目标要求推理，重写材料、问题或判定。
2. 完成者能否在未示范的新材料/变化条件下使用同一关系？若尚未安排，补独立应用；受助答对单列记录。

一次呈现一个判断，可分步调取原文、证据和理由；精简的是竞争信息，关键机制、上下文与证据保持可达。反馈指出实际原句、对象、关系或条件，并允许修订。简单识别/稳定执行目标可保留相应任务，记录目标依据；不按固定次数、题型或“高阶”标签增加负担。

## 分层选用方法，不寻找唯一脚本

不同框架解决不同层次的问题，不能将名称叠加后当作教学质量：

| 层次 | 默认用途 | 使用边界 |
|---|---|---|
| 课程规划 | 逆向设计、建构对齐：目标 → 证据 → 教学活动 | 它们决定对齐，不决定固定课堂节奏 |
| 完整任务 | Merrill 的任务中心；复杂职业技能按需参考4C/ID | 简单概念课不为“整任务”制造大型项目；4C/ID不作为所有短课模板 |
| 教学过程 | 认知学徒制的示范、教练、脚手架、表达和反思；Rosenshine用于检查小步呈现、提问、引导练习与独立练习 | 不要求每场依次出现全部事件，也不把课堂变成连续小测 |
| 动机 | ARCS检查注意、相关、信心和满足的缺口 | 动机设计不能代替知识讲解、练习和评价；不开场堆悬念或奖励 |
| 媒体 | 多媒体学习原则检查删减、信号、时空对应与分段 | 研究条件与无障碍需求优先；字幕和等价路径不能因“冗余”被删除 |
| 反馈评价 | 形成性评价：取证 → 解释 → 教学决定 → 学生修订 → 再检查 | 显示正误、收日志或统一评语不是完整闭环 |

Gagné九事件可作遗漏检查，5E可用于适合探究的科学任务，Bloom修订分类可描述认知要求；三者都不是默认主线。ADDIE属于项目过程框架，不替代一堂课的学习路径。[LS2、LS3、LS12—LS17]

## 以整任务组织，但按条件选择顺序

先用一句可观察的完整表现说明学习者最终要做成什么，并在开场或首个教学场景让学习者看到实际问题、材料或成品标准。整任务不是先让新手盲试，也不是必须一次做完；它用于给后续概念、步骤与媒体一个共同方向。[LS12、LS14]

按以下条件选择顺序：

- `demonstration_first`：先修不足、任务关系复杂、错误代价高或界面本身陌生时，先示范再练。
- `attempt_first`：先修可用、尝试安全且首次表现确有诊断价值时，先保存假设或方案，再给予示范和反馈。
- `mixed`：先做低风险预测或局部判断，再示范完整过程，随后完成关键步骤。

记录选择依据，不按学科名称自动决定。初次尝试不能要求未教内容必须答对；示范也不能提前泄露要保留为独立评价的当前题答案。

## 创作意图、知识控制与作品迭代

数学/科学与创作结合时按[Pixar in a Box 的课程转译](pixar-in-a-box-for-learning.md)执行；这是公开课程机制的教学转译，不能用作效果研究或通用学习科学标准。先确认创作是否服务本课目标，纯概念、史料解释或程序基础不必强造艺术作品。

适合时先写希望作品达到什么效果、服务谁、学生能决定什么。明确作品特征、工具可控量、图/数据和概念/公式的对应；让技术解决具体问题，例如插值改变运动节奏，而非只为升级工具安排新谜题。先修不足可先示范后创作；固定数据练习和新材料独立任务继续承担程序能力与理解取证。

作者决定可以有限，但须实际影响结果。测试比较计划与实际，定位问题，修改或说明为何保留，并用学到的关系解释。数学/物理、可实现条件和艺术表现分别判断；多个满足条件的作品不被压成同一答案。完整作品、正确试验结果或满意度不能代替个人理解。

工具若直接算出解或提示关键步骤，登记该次结果为试验或受助证据。独立能力按目标声明正常可用工具与反馈时机；不能拿揭示答案后的抄录作独立求解，也不能因“独立”而禁用所有资料和无障碍支持。作品前后版本与解释用于看见迭代，不强制每场创作、固定轮次或真实展示。

## 区分讲解、示范、引导练习和独立应用

讲解说明概念、规则或关系；示范让学习者看见如何完成过程及专家判断。需要示范时，至少写出：

1. 实际材料与目标。
2. 每一步做什么、为何这样做。
3. 方法成立的条件与边界。
4. 怎样检查结果。
5. 示范后由学习者接着完成哪一步。

示范可用完整例题、思维外显、对比例、作品修订过程或操作演示。开放问题展示一种合理过程和评价依据，不把示范作品变成唯一标准答案。[LS4、LS13、LS15]

引导练习必须让学习者完成目标中的关键知识动作。提示可从对象定位、关系提示、局部示范到完整示范逐步增加；撤除依据看当前表现，不按固定答错次数。独立应用使用新材料并撤除当前目标的答案性帮助，但保留真实工作所需资料、工具和无障碍支持。[LS7、LS13—LS15]

## 根据基础与任务调整指导

每个任务声明 evaluator（确定性规则、自评、人工或已验证 AI）、可判定输入、`uncertain`/`review_pending` 条件、补取证动作、帮助级别、撤除/退出条件和恢复方式。人工负责开放解释与边界判断；自动规则只处理已声明的可观察条件；自评不能自动升级为掌握。任何路线都保留首答、使用过的帮助、修订和帮助撤除后的独立再查。

新手面对复杂关系时，优先提供可理解的讲解、示范与引导练习。已有较好基础者可减少重复说明，增加独立判断和变化条件。调整以实际表现为依据，不根据学习风格标签或观看时长猜测。[LS1、LS4、LS7]

按需要采用示范 → 补全关键一步 → 独立处理新问题。每次示范说明为何选此方法、条件与检查方式，并让学生接着做实际任务。对于历史、语言与创作，示范推理或修订过程，避免把开放问题变成唯一标准范文。

把帮助分成：

- 基础输入：术语、前置关系和操作示范。
- 当前知识提示：指向关系、关键步骤或证据。
- 完整解答：显示本题推理或答案，明确记录受助。

提前写帮助撤除依据及再次求助入口。撤除可先去掉关键步骤提示，保留正常可用资料和无障碍支持；“独立”不自动等于闭卷或不得用工具。独立任务的允许资源须符合该能力的真实条件。

情境教学不等于隐藏教学。可让问题、练习与反馈来自同一事件，必要概念、专家思路和关系仍应适时明确呈现；由具体体验提炼规律，再在新条件下使用，不能把解谜成功当作已经形成可迁移知识。按需深度由本领域先修与表现决定：共同主线覆盖必需能力，补救支持直接可达，进阶改变条件、解释要求或创作空间，不以隐藏核心知识或收集彩蛋分层。[LS1、LS4、LS7、LS13]

不按固定答错次数升级帮助，不把每个目标强制拆成同样多段。开放回答无法可靠解释时先追问或交给审阅，不能由错误关键词直接指派补救。

## 管理注意力与表征

把需要对照的图、对象、数据与说明放在可对应的位置，适时高亮当前关系；必要时暂停、分段、回看或提供静态教具。精确内容由确定规则保障。[LS4、LS7]

具体物件、动态图、文字、图表与公式之间明确指出对应关系。颜色、比例、空间距离和角色行为的类比有边界时须说明；不要让学生把艺术构图当成数据。

逐场检查同时处理的新术语、变量、资料、控件和情节信息。优先删去不服务当前目标的负担，保留必要推理，不用“更轻量”省掉机制讲解或综合判断。没有通用的人数、屏数、时长或容量数字可直接保证认知负荷合适。

有声讲解提供字幕与静音等价路径；不能用“避免冗余”原则删除无障碍信息。字幕、旁白、图形和密集原文同时呈现时，通过可控播放、布局和分步揭示解决竞争。

## 检索、间隔与辨别练习

优先考虑让学生尝试从记忆中提取关键关系、步骤或解释，再核对与修订。看着答案重读或被高亮引导点选，不构成检索练习。[LS4、LS5]

将检索嵌入当前事务，例如不看旧图先预测受阻结果，再打开模型核对。不要求每场额外测验，不把频繁答题等同于更有效。

对需长期保持的目标，写明何时在后续场景、课时或延后任务中再遇到它，使用什么提示与反馈。单次短课没有课后触达能力时，明确可实施范围；课内回访不能冒充已验证的长期保持。间隔按内容、先修、预期保持时间与实际安排制定，不固定“1／3／7天”。

需要辨别相近概念或方法时，可在建立基础后混合适当例子，要求选择方法并说明依据。IES 的“例题与解题交替”与不同题型的“交错练习”不是完全相同的做法。不要为交错而随机切换无关学科；较困难的当下练习也不自动等于更好的延后学习。[LS4、LS5]

## 迁移、反思与自我调节

让学生先识别什么关系仍成立、什么条件变了，再独立应用。按需要使用反例、边界例、表征变化或证据不足情况。检索有助于学习，但它对迁移的效果受任务与练习条件影响。[LS8]

新建或修订迁移任务时，先保存实际基线材料与新材料，再逐任务写 `transfer_contrast`：`baseline_reference`、`current_reference`、`invariant_target`、`changed_dimensions` 和 `required_reasoning_adjustment`。每个变化维度写 `kind`、`before`、`after`；kind 可为 `condition`、`data`、`evidence`、`constraint`、`representation` 或 `object_property`，必须说明变化为何要求重新判断。仅改名称、措辞、位置不能充当实质变化；仅换对象外观也不足以自动成立。

检查学习者能否原样复制示范的依据和结论。若能且目标要求迁移，改数据、条件或证据要求，并同步题干、答案、反馈和量规。新任务仍对准已教能力；新增概念或阅读负担需先支持。变化真实性、难度可比性及迁移范围由实际内容审阅判断，机械检查只查声明与引用。按[评价完整性](course-evaluation.md#评价完整性合同)编入 sidecar；`transfer_review` 保留 pending，直到本版材料获得实际语义审阅。

按目标决定是否需要表达与反思。机制、推理、技能和创作通常要求学习者说出所用依据、步骤选择、适用条件、与示范的差异或仍不确定之处；可嵌入练习、独立应用或结课，不强制新增反思页。仅需稳定识别或执行的简单目标若不单设，记录理由。

结课可让学习者按量规指出作品或解释的具体缺口，选择回看或下一练习，再用新任务核对。反思用于暴露和组织思路，不自动证明掌握；自信、兴趣与自评用于理解学习过程，自报“我懂了”不能替代任务表现。[LS12、LS13]

## 共创项目中的个体学习

仅当目标包含设计、制作、协作或表达时安排学生共创，不把制作团队跨工种协作直接视为学生 PBL。每个分工明确知识动作、交接输出和在共同作品中的用途，记录实际教学与支持；角色名和展示不能替代学习任务。

通过目标相关的个体解释、交叉检查或新材料任务，取得每人对必需概念的证据，避免只有计算/工程组接触知识。团队成品、角色专项技能与共同必需能力分别评价；不因表演精彩或装置能运行就给全组相同掌握结论。单人课可以依次设计、测试与解释，不强加虚构小组。

具体设计是 Imagineering 思想的教学转化，不据此宣称 PBL 或故事教学必然提升记忆；评价仍按既有目标与证据链执行。
