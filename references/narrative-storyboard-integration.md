# 剧情—教学—分镜协同

剧情不是课程外壳，分镜不是镜头清单。先按 `imagineering-for-learning.md` 明确目标知识对当前理解、预测、制作或判断的价值，再把行动链转成可见、可听、可操作、可制作的节拍和镜头。不能把“有价值”夸大成现实唯一办法，或把线性事故故事当作沉浸式课程唯一形式。

先按 `narrative-scale-and-perspective.md` 选择本课叙事路线，分开确定解释尺度、知识焦点、镜头视点和学习者权限。全程整体、全程局部、整体与局部切换均可成立；不默认宏大开篇后逐个热区进入局部。下述人物戏规则用于有实际人物行动的范围；纪实与系统叙事按条件、过程、关系变化和证据组织，不为套用戏剧结构虚构人物动机或冲突。

## 一、先判定是否需要剧情

只有满足至少一项时使用连续剧情：

- 学习目标需要在角色、对象、证据或环境随时间变化时作判断。
- 知识的用途通过真实职责、约束、代价或协作关系才能被理解。
- 错误、修订和迁移会自然改变事务状态或角色下一步。
- 课程需要连续空间、对象或事件承载观察、操作和反馈。

出现以下情况时，弱化或取消剧情：

- 冲突与目标知识无因果关系，只为制造热闹。
- 任意职业、地点或角色都能替换，学习任务和反馈完全不变。
- NPC 只负责念题、夸奖、催促或宣布下一关。
- 学习者的选择不改变证据、对象、权限、关系、风险或下一步。
- 需要不断用旁白解释“为什么现在要做这道题”。

写一句情境必要性证明：

> 因为现场角色要完成 **[具体事务]**，但受 **[真实约束/信息缺口]** 阻碍，所以学习者必须使用 **[目标知识或方法]** 对 **[证据/对象]** 作出 **[可观察判断或行动]**；结果会改变 **[现场状态]**。

这句话不能成立时，先修课程情境，不写分镜。

“必须使用”指本次学习需要取得真实知识证据，不意味着现实没有其他方法。把测量、查表、试装、其他算法等最合理替代带入情境，解释本方法的收益与边界；若无法解释，改为诚实的模型探索、示范或创作任务，不编造工具故障与专业人员无能。逐式检查变量是否仍指向当前对象：为练下一种解法突然给出无来源方程，不能靠同一张图纸声称连续。

纪实/系统路线改写为：“要解释或处理[整体/局部问题]，目前缺少[关系证据]；学习者运用[方法]比较/预测/组织[当前对象]，结果修订[解释/模型/方案]并引出[下一问题]。”目标不需要连续剧情时保留清楚的观察或教学过程。

## 二、建立双因果脊柱

剧情课程同时维护两条因果链，不能一条推进、另一条停滞。

### 戏剧因果

`角色当前目标 → 阻力/约束 → 行动或选择 → 可见后果 → 新压力/下一问题`

纪实、宏观或系统叙事使用 `起始条件 → 行动者行为/系统过程 → 关系变化 → 后果/新证据 → 下一问题`。明确来源、简化和推断边界；不要求每拍有角色争执，也不把全程整体路线改成局部人物任务链。

### 学习因果

`学习者信息缺口 → 取得证据 → 运用知识判断/操作 → 反馈与修订 → 能独立处理的新条件`

逐场用“因为—所以—但是—因此”串联：

- **因为**前一场产生了什么事实或状态；
- **所以**角色和学习者现在必须做什么；
- **但是**什么阻力或未知使目标不能直接完成；
- **因此**当前学习行动会造成什么后果并引出下一场。

只靠“然后”连接的场景通常是目录，不是剧情。若一场结束后人物、事务、对象、证据、关系、风险和学习状态均未改变，删除或合并。

因果表不能替代戏。进入场景时，人物的工作、争取、试探或分歧可以已经发生；让观众从一个能理解的动作和回应追上现场，不强制先听完主持简报。台词中的“先”“再”可以用于真实协作，问题在于人物是否只按教案排队发布步骤。不能靠删除连接词、添加争吵或搬动道具，把相同的流程稿伪装成剧情。

## 三、角色与学习者行动契约

### 关键角色

为承担主要剧情功能的角色填写：

- 当前职责和可验证目标；
- 已知、未知和错误判断；
- 可用资源、权限和限制；
- 面对阻力时会采用的策略；
- 学习者正确、错误、求助和修订时的实际回应；
- 场景结束后的新状态。

配角只在承担冲突、证据、协作或后果时展开，不为“丰满人物”硬加秘密和反转。

### 学习者

学习者角色必须解释：

- 为什么由学习者而不是 NPC 作这个判断；
- 学习者能看到哪些证据、能改变哪些对象或记录；
- 哪一步必须自己思考，不能由角色、按钮措辞或动画代做；
- 错误如何产生可恢复的后果，而不是无条件回弹；
- 学到的能力怎样让后续行动从受助变为独立。

学习者不是镜头里的隐形观众，也不是替 NPC 填空。NPC 不能在学生提交前泄露判断所需结论。

角色关系可由共同好奇、对作品的投入、真实协作或对新手的帮助建立。写出其关注的对象和回应方式即可，不强制悲惨身世、秘密、争吵或“全场只有学生能救”。人物熟练度、工具能力、权限和物理条件必须经得起常识核对。

### 承诺核对

每个“你的判断会改变……”承诺，对照正文走两种具体输入，追踪 **输入 → 当前对象/记录差异 → 下一镜回应 → 关闭/帮助/汇合后保留的状态**。写下实际差异及其位置；同一结果不能同时声称由互斥输入决定。只改变诗页、图线或计划记录也可有真实用途，承诺应准确限定到该对象；线性观察和明确示范不强制改变人物路线。

核心行动由人物/系统执行时，把当时已有的需要、条件或判断依据演在行动之前，再让观众见证变化。教师先示范、学生后练习可以成立；判断的是该行动有无来由，不把示范误当应由学生先独立完成。角色可以不知道某一概念，也应有面对当前对象的尝试；把多个不相关误解依次交给同一角色时，审其来由与策略。

## 四、控制冲突、赌注和信息

- 赌注与学科事实、职责和学习者能力相称。普通课程优先使用返工、误判、资源浪费、解释不清、决策延迟、对象状态异常或服务质量等可恢复后果。
- 灾难、倒计时、反派、阴谋和不可逆损失只有来源或题材确实需要时才使用。
- 冲突来自目标与约束，不来自角色突然变笨、系统无故失灵或权限刻意卡住。
- 悬念可以延迟原因和最终结论，不能隐藏当前判断必需的数据、单位、规则或证据。
- 学习困难与剧情阻力可以相互映射，但不能把错误学习者写成道德失败者。

## 五、场景契约

每个剧情场景至少登记：

| 字段 | 要求 |
|---|---|
| 场景功能 | 本场不可替代的剧情和教学作用 |
| 尺度与焦点 | 当前整体/局部关系、知识证据粒度、视点和参与范围；变化或保持的理由 |
| 进入状态 | 人物目标、对象、证据、学习者能力和未解问题 |
| 触发原因 | 前一后果、环境事件、角色行动或新证据 |
| 焦点问题 | 角色要办成什么，学习者必须判断什么 |
| 阻力 | 事实、约束、误解、冲突或操作限制 |
| 学习者行动 | 取证、计算、比较、操作、解释或修订 |
| 可见后果 | 对象、记录、关系、权限、风险或下一步怎样变化 |
| 学习变化 | 新获得、修订或仍未掌握的能力 |
| 场尾状态 | 已解决什么，留下什么新压力 |
| 下一场来由 | 为什么必须在此时进入下一场 |

教学讲解场可以弱化冲突，但仍需有明确观察对象、信息变化和后续学生行动。不能用角色长对白替代示范过程。

新材料、工具、方程或尺度进入时，在正文交代来源、当前使用理由及它怎样带回原事务/解释。直接标明简短教学示范也可成立，保持该插入与后续行动的关系。数学变量和单位仍指向已给对象，史料与合成记录身份持续可读；来由说明只提供必要条件，独立判断的结论仍按评价 owner 的揭示时序保留。

## 六、先审实际剧本，再做分镜

节拍板帮助组织因果，写完后须把它落实成实际动作、对白、声音和留白。编译生成提示词之前，做一次只读剧本的独立审阅：

- 暂时移开目标表、作者解释、场景功能和“此处有悬念”等质量标签。观众实际接收到什么才是审阅对象。
- 找出人物此刻向谁争取什么，以及对方的回应如何改变其策略；事务性角色可以简短，不强加人物秘密或反转。
- 按[可录制台词与口语审阅](spoken-language-and-review.md)看对白对眼前对象或关系做了什么。逐条念教案再换口语词，仍不能成为人物行动；必要的概念解释、示范、操作说明与具体回顾可以直接讲清，不因它是说明就判为失败。能演清且无需教学重述的变化不再复述。
- 检查开头是否让人关心具体未完成的事，结尾是否由本场行动留下变化或未解问题。一般工作、误会、协作和安静场景也可成立，不强加危机。
- 指出至少一处具体台词与动作的关系，并记录仍薄弱的地方；不能用“有目标/冲突/后果”勾选表证明吸引力。
- 分开核查内容来源。角色的看法、教学创作的对话和情境后果不冒充史料、真实案例或学科定论；创作披露放在合适入口。

无人物戏的宏观/系统脚本改查实际条件、过程、关系变化与学习者判断；不以缺少人物诉求判为失败。逐次尺度切换须能从正文和对象看出为何进入、获得什么、怎样改变原解释；全程同一尺度不强制制造切换。

审阅失败先改剧本，不能靠更细的运镜、情绪形容词、配乐或生成质量补救。自审结果是创作判断，不是人类确认，也不证明学习效果。

审阅步骤与范围/字节/原句记录按[分镜独立审阅](storyboard-review.md)。实际自审标明作者关系；一项判断引用的材料必须出现在被读正文中，未提供的材料保持缺失或未评。

无连续剧情的课程也执行全范围口语审阅；覆盖正文、成立/误解反馈、各层帮助、重试、返回、恢复和结尾。先提取纯台词整段审，再查触发条件、必要教学与实际动作；结果写入既有 `verification.md`，不新增许可门。

### 节拍板到分镜

设计阶段先写 beat board，通常 6–12 个关键节拍；数量由任务决定。每个节拍填写：

| 字段 | 要求 |
|---|---|
| Beat ID | 稳定英文标识 |
| 剧情变化 | 人物、事务、关系、风险或对象状态怎样改变 |
| 教学变化 | 学习者取得什么证据、使用什么知识、暴露什么困难 |
| 叙事尺度与知识焦点 | 当前解释层级和证据粒度；与上一拍相同或切换的依据及带回的结果 |
| 学习者问题 | 此刻自然会问什么，不是章节标题 |
| 行动与后果 | 谁做什么，现场怎样回应 |
| 必须看见/听见 | 支撑理解的对象、动作、数据、声音或沉默 |
| 交互窗口 | 何时暂停、开放什么、提交后从何处恢复 |
| 下一节拍因果 | 当前后果怎样推动下一步 |

节拍板通过后才写 shot board。用最低可回答风险的预演精度：

- **Beat board**：验证故事、教学和情绪顺序。
- **Shot board**：验证画面信息、动作、交互窗口和剪辑连续性。
- **Animatic**：验证对白、停顿、字幕、动作和交互前后的真实节奏。
- **3D previs / techvis**：只有空间、复杂调度、镜头路径或制作约束确实需要时使用。

## 七、镜头的信息任务

每个镜头先写一句：

> 学习者应注意 **[对象/变化]**，理解 **[关系/因果]**，并准备 **[下一行动]**；同时暂不强调 **[次要信息]**。

再选择镜头功能：

- **定向**：建立人物、对象、出口、距离或方向。
- **揭示**：让新证据或状态进入视野。
- **见证**：让行动和后果在连续时间中成立。
- **对齐**：与学习者、角色或工具的观察位置一致。
- **比较**：让两个对象、状态或证据可核对。
- **聚焦**：隔离决定、表情、细节或操作。
- **转场**：用动作、方向、形状、声音或注意力接续。

镜头表至少增加：

| 字段 | 要求 |
|---|---|
| Shot ID / Beat ID | 稳定引用和所属节拍 |
| 剧情任务 | 本镜头改变观众对人物或事件的什么理解 |
| 教学任务 | 本镜头让学习者取得或核对什么证据 |
| 起止画面与动作 | 开始状态、可见变化、结束状态 |
| 视点与空间 | 学习者位置、人物站位、视线、运动方向和对象关系 |
| 声音 | 对白、知识旁白、环境、动作声、留白和字幕 |
| 交互与恢复 | 开放时机、稳定等待、提交后恢复点 |
| 连续性锚点 | 人物、持物、对象、UI、光线、方向和知识状态 |
| 准出条件 | 两到三项可观察通过条件 |

景别、机位、焦距和运动服务上述任务。锁定镜头已能完成时，不为“电影感”增加运动。一个镜头优先一个主动作和一个主镜头意图；长动作链拆成可控节拍。

## 八、剧情、教学和镜头的互相校验

### 从剧情查教学

- 目标知识是否真正改变角色决策或事务结果？
- 学习者是否通过知识行动，而非观看角色解决？
- 错误反馈是否由同一证据和现场状态产生？
- 新情境是否改变条件，而非只换角色名和地点？

### 从教学查剧情

- 每个练习为什么在此刻发生？
- 示范、提示和修订是否改变人物、对象或下一步？
- 完成与理解分开时，剧情是否也允许“事务继续但能力未独立”？
- 开放题待人工审阅时，角色是否避免假装读懂？

### 从分镜查两者

- 不读作者说明，能否看懂在哪里、谁要什么、什么改变了？
- 学习证据是否在正确景别、时长和遮挡条件下可读？
- 关键数据是否由确定性教具承担，而非画面估算？
- 镜头是否尊重第一人称视点、轴线、屏幕方向和持物状态？
- 交互前后动作、声音和对象状态是否能连续恢复？
- 相邻镜头是否重复同一信息？删除后是否真的造成损失？

## 九、分支不是另一个故事

正确、主要错误、求助和修订共享同一人物目标、对象、证据和世界规则：

- **正确**：行动成立，显示原因和后果，推进下一压力。
- **主要错误**：错误产生可理解、可恢复的现场后果；反馈定位失配证据，不羞辱学习者。
- **求助**：角色或系统逐层提供对象、关系和局部示范，仍由学习者完成关键动作。
- **修订**：保留首答，学习者改变实际输入、证据组织或操作；现场状态据此更新。
- **返回**：恢复人物位置、持物、视线、声音、对象和记录，不瞬移到普通题页。

分支可以共用镜头和资产，不需要为每个答案拍一套剧情；差异集中在可见后果、回应和修订窗口。

汇合只合并时间线位置，不能抹去分支状态。后续共用视频不得口头否定学习者已作选择；用实际分支片段或确定性对象层承接差异。因正确判断、补救后成功或未形成独立证据而继续时，记录分别保留，不能统一宣布“你已经掌握”。

## 十、协同技能路由

当环境可用且任务范围需要时：

1. 用 `short-drama-write` 检查单场/连续场景的目标、阻力、行动、后果、可表演对白和退出状态。
2. 用 `storyboard-previsualization` 把已确认节拍转成 shot board、animatic、连续性表和制作交接。
3. 用 `cinematic-shot-direction` 细化高风险镜头的编辑功能、视点、机位、调度、运动、轴线和剪辑衔接。

课程编排器始终保留学习目标、来源、评价、帮助边界和状态门的最终责任。上游剧情技能不能添加未经来源支持的学科事实，下游分镜技能不能改变已确认的任务判定和证据揭示时序。

## 十一、设计确认前核对

以下任一不成立，保持 `design_draft`：

- 所选路线的情境或观察/教学用途具体；连续剧情使用情境必要性证明。
- 连续剧情的行动因果或系统/观察路线的信息变化明确，不靠章节堆叠。
- 有人物行动时，关键角色有目标、约束、策略和状态变化。
- 学习者实际参与与承诺一致；响应型互动通过承诺核对，线性路线保留真实观察、解释或记录。
- 每场进入、阻力、行动、后果、学习变化和下一来由明确。
