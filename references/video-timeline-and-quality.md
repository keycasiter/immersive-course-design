# 视频时间线、声音与实际验收

按[通用生产系统](video-production-system.md)保存计划和环境。正式准出要检查实际交付文件与全部必需视频；单个漂亮镜头或总时长够长不能证明全课通过。

## 时间线与音源

声音事件包括完整台词、实际发声区间、正常停顿、呼吸、对象动作声、环境与可选音乐。计划、生成单元、剪辑与网页使用同一组稳定事件标识；单元的相对时间由最终绝对时间减去单元起点计算。

每条视觉 clip 记录实际输出文件、源起止、目标起止、所属单元和用途。检查：

1. 声音开始前对象和说话人已成立；完整说完后保留收势，剪辑点不截字词。
2. 所有台词、动作和信息揭示在目标时间都有适合的画面。原始视频长于所用区间也要查区间是否正确。
3. 主线、分支和返回各有独立时间线；一个长单元被多个 shots 引用不重复装配。
4. 正式真人行动/讲话所需时间由真实动态素材覆盖。禁止尾帧冻结、循环、倒放或数码缩放填补时长缺口；这些效果即使改变像素，也不能补足表演或教学行动。
5. 静态教具可以在旁白下停留；互动等候可以冻结或循环环境，但必须从自然等待状态进入，且不承载画内说话。逐区间标 instructional_static / interaction_wait 与具体用途，不能用全课“允许静止”豁免。
6. 缺素材时补对象操作、合理反应/切镜、完整话轮分段或支持的延伸；不给必需内容删句、加速或提前关闭声音。

每条人声只选一个主音源：

- 正确原生同期人声保留；若另用分轨控制，避免同一人声播放两次。
- 最终固定配音替换原声时必须完成音频驱动口型，并重新验收。
- 环境/动作声和角色人声混在同一轨且不能安全分离时，重做或使用经检验的分离能力；不同时叠两个“差不多”的人声。
- 错误原声、人声重复、旧 BGM 残留不得仅用降低音量处理。

正式 MP4 内嵌本段已验收的人声及同场环境/动作声，网页另保留分轨。主视频不烘焙互斥分支的全部回应。音源主控选择、静音和切换登记到声音事件及运行时。

## 混音、字幕与交互

环境声保持空间位置与动作对应；配乐只有在有明确作用时使用，不设至少一条 BGM。人声可懂度优先，按实际听感及响度检查避让、峰值、噪声和片间变化；不能把固定音量百分比当混音准则。

尾部杂音只在听审确认正常话音、尾字和呼吸全部结束后处理，淡出不得吞掉最后一句。波形和静音检测不能单独证明“杂音已定位”。

字幕由最终音轨生成/对齐，逐句核对正文、术语、数字、说话者、开始/结束和阅读时间。不得沿用重配前的估计字幕。准确标签、图表和公式用确定性工具输出。

网页播放以媒体时钟驱动字幕、人物介绍、对象入口和事件；独立人声与视频时钟有明确主从/校正。打开任务暂停冲突轨，返回恢复正确事件和音源；不能靠各自 `setTimeout` 持续漂移。浏览器 `ended` 只表示一条媒体结束，切节点前须核对本节点必需声音和动作均已完成。

实际测试播放、暂停、跳播、重听、刷新、分支返回、窄屏、静音、后台恢复与媒体失败。交互等候从播放器暂停进入，不用黑屏或意外卡死表示等待；等价文本/教具保留完整目标。

## 自动检查

### 确定性教具与声音事件

公式、图表、对象状态或演示 UI 由可控渲染器产生时，沿用现有视觉/声音事件 ID 和对象 ID。记录渲染器与版本、输入/代码 SHA、fps、时间取整规则、实际音源 SHA、事件触发与对象落点；本次对应关系保存为制作证据，不建立第二份台词或学习状态。

渲染前从同一渲染代码导出 event trace，逐事件核对信息揭示顺序、语音相关词句的实际时点、完成/等待和尾部余量。匹配使用事件与对象身份；最近时间的任意动作不能替代目标事件。容差按动作、语音测量与帧精度声明，不套统一一秒标准。实际声音变化后重算受影响 trace。

渲染后在成片实际时点核对目标对象的状态和声音，再验证浏览器暂停、跳播与恢复。trace 预测只证明本渲染器的计算；成片编码、实际播放和教学含义分别验收。真实软件流程通过运行时录制与操作证据验收；重建 UI 显式标教学演示，不能用它证明真实应用操作成功。该分支的 trace 文件和对齐审阅登记在 media-plan 与 verification；现有视频校验器不自动验证事件语义。

### 实际接缝定位（视频计划 1.2）

接缝状态与路线遵循[导演连续性](video-direction-and-continuity.md)，字段复制 `assets/video-continuity-seam.template.json`。源区间为相对首个呈现帧的秒数，采用左闭右开 `[source_start_seconds, source_end_seconds)`；preceding_boundary 定位该区间最后采用帧，following_boundary 定位第一采用帧。记录整数 presentation_timestamp、实际 time_base、source_sha256 和边界观察证据文件/SHA。使用呈现时间而非解码顺序；可变帧率不按平均帧率换算。

`delivery_sha256_by_timeline` 覆盖参与接缝的全部当前时间线。`audible_state.listening_review` 与 continuity_review 使用现有 status/reviewer/bound_sha256/evidence_file/evidence_sha256，绑定后继成片；审阅文件同时说明前后片及其 SHA、采用区间和实际听看结果。resume 的 resume_source_seconds 定位后继 clip 内恢复时刻对应的最后一个不晚于该时刻的呈现帧；前驱仍取其采用区间最后帧。恢复时保持同一对象/声音/学习状态，实际浏览器恢复另行验收。

`--delivery` 重新探测源 PTS、核对采用边界及证据版本；它不从单张图判断物理或教学含义。当前剪辑契约使用平展、不重叠的 clip 表；淡化、重叠混音或复杂变速应先烘焙/平展到可验证源片与目标区间，保留原始映射和听审，不能只填两个相等时长冒称已检查。

运行 `scripts/validate_video_production.py`：

- 默认检查环境指纹、能力状态、参考绑定、单元与声音映射、时长档位、镜头/剪辑覆盖、重复源区间和禁用补时方式。
- `--pre-submit --unit` 读回一个未提交单元的最终参数与权威台词；具体指纹、适配器和恢复由媒体 Job owner 定义。
- `--manifest` 核对生产清单中的必需正式视频与计划资产；`--blueprint` 核对必需视频资源，防止只检查一个小样就声称全课通过。
- `--delivery` 对各正式文件和源片做 SHA256、ffprobe、完整音画解码、流终点、人声源范围与实际非静音区间检查。
- 对实际交付视频以 24 fps 缩小灰度扫描检测低变化区间，用全局均值和变化像素比例同时判定疑似冻结；这不是源 PTS 级接缝或全帧正确性证明。阈值可在环境中配置，不能放宽阈值掩盖缺陷。
- 画内近景说话或精细手部动作时，在时间线的 `motion_regions` 登记实际归一化矩形 `[x,y,width,height]` 与用途，局部以更灵敏阈值检查微动；不能把压缩噪声和自然口型混为一谈。人物或相机运动使区域失效时重定区域或分段核查，不用空区域声称已检查嘴部。
- 实际动态讲话发生疑似冻结时阻断；普通真人静止区间需要具体听看核对记录，不能以“有音轨/总时长够”放行。静态教具与等候仅在对应 clip 的明确用途范围成立。
- 正式检查要求本版文件绑定的人工内容、声线、口型、字幕/事件、连续性与听感证据。脚本不验证审阅人身份，也不代替知识、听感或精细口型判断。

工具依赖：Python 3、NumPy、ffmpeg、ffprobe。检测在临时工作目录运行，不改媒体。冻结扫描使用采样时间，接缝另用实际源 PTS；编码噪声、数码缩放、局部动作和运动模糊会影响判断。自动检测仅能找到候选冻结，不能证明真实物理动作、对白正文或全帧正确。

生成小样/正式准出分别保存接触表、首尾/接触/释放帧、逐句听审、原生与重配对照、字幕、实际范围和脚本报告。疑似问题的人工复核记录到具体时间区间及 SHA256；不能只填写全片 passed。

`manual_reviews` 每条使用以下字段。六项 `check` 分别为 content、voice_identity、lip_synchronization、subtitles_and_events、continuity、listening；不适用口型也须在实际审阅文件说明旁白/静态等路线。Agent 不代签人类确认；这些是已执行质量审阅的记录。

```json
{
  "timeline_identifier": "mainline",
  "check": "listening",
  "status": "passed",
  "reviewer": "实际审阅者或执行工具",
  "bound_sha256": "实际成片SHA256",
  "evidence_file": "audio-review.md",
  "evidence_sha256": "实际审阅文件SHA256"
}
```

`freeze_reviews` 另加实际 `start_seconds`、`end_seconds` 与具体 `reason`，只用于不与实际发声交叠的待核静止区间。`silence_review` 绑定被检查音源及其源时间，说明被误判为静音的轻声/呼吸区间与听审结论；不能用此项掩盖漏字。原生主音源 clip 填 `retain_embedded_audio=true`；外配主控完成口型后显式管理旧音轨，避免重复人声。

## 交付记录

`video-production-plan.json`、`video-production-environment.json`、job 与时间线、原始候选、最终 MP4、声音分轨、字幕、接触表、逐项审阅及 `video-validation.json` 均按生产清单登记。审阅记录和 report 绑定本版成片、音源和参考指纹，替换文件后重验。

计划、自动检查、人工媒体验收、功能验收及人类确认分开报告。旧课未执行新检查时写“未按本版检查”，不追认通过；仅更新 Skill 不重做课程。
