# 课程成品页面：UI、布局与品质

本模块用于课程页面设计、已有页面迭代和组装后的成品打磨。先按学习任务组织画面，再处理字体、颜色和细节。设计范围可填写页面方案；实现范围必须检验实际页面。审美判断、浏览器实测和学习效果分别记录。

## 能力选择与读取

用户指定工具优先；已有教学设计、画像、视觉圣经和页面设计契约就是设计上下文，不重复采访。

| 能力 | 在本流程中的职责 | 使用边界 |
|---|---|---|
| UICraft | 主要执行器：构图、排版、响应式、界面文字、交互状态与成品核对 | 当前项目已有完整 Skill；执行时从当前技能目录读取主模块及本次所需参考 |
| Anthropic `frontend-design` | 补充明确的视觉方向、内容层级、空间节奏和细节完成度 | 本地同名摘要不能当成完整指令；只有完整模块可用时才调用 |
| `impeccable-design-polish` | 对已有页面进行审阅、精简、打磨和边界修复 | 不从头重建已确认课程；与 UICraft 重叠的检查只执行一次 |
| `ai-style` | 中文界面文案审阅的补充 | 按对象、动作、结果改写；保留正确术语、证据、必要限制和具体教学反馈 |

UICraft 每轮选择一个主要工作流，再读必要基础参考：

| 当前问题 | 主要参考 | 需要时补读 |
|---|---|---|
| 初次确定方向或页面显得通用 | `references/critique.md` | 空间、字体、认知负担 |
| 主次不清、卡片堆叠、比例不合内容 | `references/arrange.md` | `spatial-design.md` |
| 中文阅读、公式和资料排版 | `references/typeset.md` | `typography.md` |
| 手机、横屏、缩放后失衡 | `references/adapt.md` | `responsive-design.md` |
| 重复说明、空泛口号、信息过量 | `references/distill.md` 或 `clarify.md` | `ux-writing.md` |
| 功能路径已通，收紧细节 | `references/polish.md` | 本次暴露的基础参考 |
| 缺状态、遮挡、焦点或媒体失败 | `references/harden.md` | `interaction-design.md` |

能力名不证明已安装、可运行或已验收。临时试用目录不成为持久依赖。完整外部模块缺失时按本模块完成已授权工作，并如实记录工具情况；不因此自行安装或覆盖全局 Skill。

## 先建立本课页面设计契约

完成体验形态决策并确认网页交付适用后，复制 [页面设计与审阅工作脚手架](../assets/page-design-contract.template.md) 为本课 `page-design.md`，关联课程版本、实际入口和媒体。它只是 `design_draft`，必须替换为真实内容并补运行证据。已有原型先查看真实页面，保留本版基线；新课使用实际题干、最长必要资料和真实素材比例进行构图。

写一句具体的视觉方向，例如“让学习者在清晰的演示纸上测量、划改，再把修改交回现场人物”。接着说明主对象、阅读方向、资料载体、操作位置和手机变化。只写“现代、简洁、高级、沉浸”不足以指导实现。

选择少量相关参考，逐项说明借鉴的层级、字重、留白或资料排法。已有课程参考只证明该课的选择，不是所有学科的固定版式。记录参考来源，不能把参考截图冒充本课产物。

设计契约至少固定：

- **注意力**：本状态要先看什么、依据在哪里、随后做什么；正文、字幕、人物和操作不争抢同一位置。
- **构图**：主对象尺度、阅读宽度、辅助信息位置；角色参与、裁切及热区锚点。
- **样式**：按用途命名的颜色、字号、行高、间距、层级、边界和焦点 tokens。
- **状态**：实际任务、资料、求助、修订、待审、返回、恢复、静音和媒体失败。
- **实现与证据**：交付技术、资源依赖、实际测试设备、截图与操作轨迹、问题和修复。

上下文充分时直接作出可逆设计选择。涉及教学含义、制作约定或确认小样的变更，沿用[原确认范围规则](production-manifest.md)，本模块不增加第三道审批门。

## 页面设计稿需要可见

当最终学习者交付形态为网页/交互页面时，课程设计阶段的 `page-design.md` 除设计原则外，还要呈现可审阅的页面草稿：用实际课程标题、真实任务文字、资料对象和主动作，分别示意至少一个桌面首屏/核心工作面与手机顺序。线框可以是文本图、表格或图形，不要求写 HTML；它必须让评审者看出主对象、证据位置、当前动作和反馈如何排列。

线框需覆盖本课独有的关键教学状态（例如史料阅读、判断、错误提示与修订、结课作品），并说明尚未实现。若用户只要求页面方案，交付线框与状态设计，不把它描述成可运行页面；若用户授权页面实现，则继续按原型/实现范围完成真实运行验收。

## 固定语义结构，按内容选择布局

`video_led_web` 先执行 `scene-participation-design.md` 的动作与表面选择，专属体验配置覆盖本节通用工作面形式。直接控件不必套 `.task-surface`；同对象的阅读、写作或实验深层视图可按任务需要占据舞台，保持入口、暂停、反馈和精确返回。卡片只容纳有界的当前问答或帮助；不使用缩字、裁掉原文或强加3D来容纳长内容。

按[页面运行时结构](page-structure.md)保留 `main#course-stage`、9个唯一直接子区域、单一工作面及返回/媒体恢复规则。区域名称、任务顺序和主次动作语义稳定；CSS 网格、比例、对齐、工作面宽度和资料载体随内容调整。

在同一个 `.task-body` 内可对照资料、教具、批注或作品，不拆成同时运行的多个任务弹层。以下是可选布局，不要求每课集齐：

| 当前学习内容 | 桌面构图 | 手机与缩放 | 核对重点 |
|---|---|---|---|
| 现场观察与人物行动 | 媒体为主；当前入口贴近对象，字幕与动作处于安全区 | 按关键对象重构裁切；必要时使用专门构图或完整画面 | 人脸、手、器物、热区和字幕不被遮挡；等待入口持续可用 |
| 测量、变量或结构教具 | 教具占主要面积；标注贴近对应位置，少量操作靠近作用对象 | 教具保留可读尺度；操作可置于下方，必要平移/缩放有等价路径 | 图形不因栏宽失真；数字、单位、关系与结果完整可见 |
| 史料、证据与文书 | 正面阅读面；同任务的短批注或作品可在侧边对照 | 原文与批注顺序呈现，保留引用锚点、已选证据和阅读位置 | 长文不居中成窄碎段；不以装饰纸渍、透视或字体牺牲阅读 |
| 判断、反馈与修订 | 当前作品和依据为中心；反馈靠近出错位置，修订动作明确 | 问题、学生答案、相关反馈按阅读顺序排列 | 不把整个任务变红；不移动或清空已填内容，不提前揭示答案 |
| 结课作品与记录 | 作品、实际表现和相关回看形成层级，可使用常规阅读布局 | 单列展开作品与记录，下载/删除入口可访问 | 未评估或待审不显示掌握率；回顾按课程开放规则呈现 |

桌面并列对照本身可以合理；是否属于场景内互动由对象入口、实际操作、暂停与返回、角色参与和状态接续判断，不能只凭左右栏形式判断。首次体验仍只显示当前任务及所需证据。

## 视频主导视觉准出门槛

本节是 `video_led_visual_gate` 的唯一 owner。它把“视频主导、页面克制”转成可检查的交付条件，不用审美偏好替代验收。

### 状态契约

| 页面状态 | 必须占据注意力的对象 | 允许出现 | 准出条件 |
|---|---|---|---|
| `playback` | 当前视频事件 | 视频、字幕、按需呼出的控制、与当前对象绑定的入口 | 视频是唯一主舞台；常驻课程标题、侧栏、目录、页脚、结果卡和装饰导航均隐藏 |
| `paused` | 当前视频帧与一个知识动作 | 当前对象、必要材料、一个主动作、一个必要辅助入口 | 媒体暂停；只保留一个工作面；学习者无需离开当前事件即可开始判断 |
| `feedback` | 学习者当前回答及对应证据 | 针对错误位置的反馈、帮助、修订控件 | 反馈改变证据、关系或作品状态；不新增与当前任务无关的卡片、徽章或进度装饰 |
| `return` | 原视频事件 | 原时间、字幕、焦点、草稿和必要对象状态 | 工作面关闭后回到原事件；不留下旧题卡、结果长文或悬浮装饰 |

### 装饰元素登记

每个不承担视频内容、字幕、当前对象、证据、操作或状态反馈的视觉元素，必须在 `page-design.md` 的装饰登记中填写：

```text
decoration_identifier
state_scope
visual_role
teaching_purpose
removal_loss
asset_or_css_reference
acceptance_evidence
```

准入条件：

1. `teaching_purpose` 必须指向当前学习动作、可读性、对象定位或状态反馈；
2. `removal_loss` 必须写出移除后损失的具体学习功能；
3. 只承担品牌、氛围、填空、炫技或“看起来更丰富”的元素不进入成品；
4. 装饰动画不得常驻、阻挡主动作、延迟提交或改变学习者等待时间；
5. 同一状态中不得用多个视觉容器重复表达同一标题、进度、帮助或结果。

### 阻断与证据

以下任一项失败，视觉准出为 `blocked`，不得推进 `interaction_complete_prototype` 或 `functional_accepted`：

- 播放态存在未经按需触发的课程壳层或非当前事件面板；
- 暂停态存在两个及以上并行任务面板，或视频与工作面无法同时辨认；
- 反馈/返回后仍残留旧任务层、装饰性结果卡或无来源进度；
- 装饰登记缺少 `teaching_purpose`、`removal_loss` 或验收证据；
- 桌面、手机竖屏/横屏、缩放、静音和减少动态效果中任一状态破坏主对象、字幕、证据或主动作；
- 只提供静态截图或 CSS 结构，没有实际播放/暂停/反馈/返回的浏览器证据。

`video_led_visual_gate` 至少保存：状态截图或 DOM 证据、视口和浏览器、进入动作、预期状态、实际结果、证据哈希和未执行项。通过样式检查不等于通过视觉准出；通过单个代表性状态也不等于全课通过。

## 中文阅读与视觉细节

- 中文正文优先使用清晰的系统字体或已许可本地字体。显示字体只在必要短标题使用；不为新奇强制换成难读字体或外部字体服务。
- 字体层级少而明确，正文通常从18—19px、行高1.7—1.9的现有基线开始；按材料、字体和实际设备调整。资料行长按汉字阅读核对，不照搬英文45—75字符的指标，不通过缩小文字容纳全部内容。
- 标题靠字号、字重和留白建立层级。长题干可折行，按钮保留完整动作；检查中文标点、长人名、中英文混排、负号、上下标、单位和公式。
- 间距使用一套 tokens，相关内容靠近、不同任务组留出间隔；按内容紧密程度改变节奏。圆角、边界和阴影表达载体或层级，不给每段文字套卡片。
- 颜色先保证文字与资料清楚，再表达选中、错误和状态。普通文字对比度至少4.5:1；满足大文本定义时至少3:1，按 [WCAG 2.2 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)计算。视频字幕须覆盖实际明暗帧验收，不能只测一张背景。
- 颜色不单独承担正误、选中或焦点含义。焦点、标签、引用标记和禁用原因可辨；保留原生控件语义。
- 图标风格一致，重要图标按钮有可访问名称。教具图形、公式和数据按内容规则制作；图片不能仅为填满空白而添加，正式素材沿用资产准出要求。
- 动态表示取放、状态改变、人物参与或空间关系。装饰动画不常驻、不延迟提交；减少动态效果时保留完整结果、位置与等价操作。视频、音频和字幕继续使用真实媒体时间轴。

## 去掉通用模板感与文案套话

把“AI味”拆成可定位的问题，记录页面、状态和实际修复。颜色、卡片、圆角或系统字体均不是单独的判错依据。

| 可观察问题 | 改法 | 必须保留 |
|---|---|---|
| 任意课程都能套用的巨型标题、发光渐变与功能三卡 | 用本课实际对象、资料和动作建立层级；删去无教学作用的装饰 | 必要背景与首个问题 |
| 每段正文都有边框、图标和独立标题 | 用阅读顺序、间距、批注和必要分隔组织 | 来源、完整原文及引用位置 |
| 同一个按钮前后反复解释如何操作 | 明确按钮动作，删除重复说明 | 不熟悉操作或无障碍确需的说明 |
| “开启探索之旅”“解锁知识”“轻松掌握”“太棒了” | 写当前对象、具体操作或已发生的结果 | 有依据的角色情绪与具体教学鼓励 |
| “再想想”“答案错误”后只能重复提交 | 指出相关证据或关系缺口，给可执行的修订入口 | 首答记录、评价边界和补救顺序 |
| 华丽数据卡、进度数字和掌握率无来源 | 显示真实作品、已保存状态、待审或实际表现 | 确有记录的数据及其含义 |
| 后台词、工具名、调试码或验收话术出现在学习流 | 改为学习者能理解的失败原因与恢复动作，详细诊断放制作记录 | 权利披露、隐私说明和必要限制 |
| “待核查、继续核查、证据收集、目标状态、任务完成”等内部流程词成为按钮、进度或NPC台词 | 写当前对象、学习者动作、NPC/对象回应和下一段事件；内部状态只留在记录 | 数学验算、代码审查等真实学科/职业术语，但不外显系统流程 |
| 多门课都套“审核台、观察台、实验台、工作台、控制中心+某某员” | 从本课现象、文本、人物、作品或事件直接进入；只有真实任务需要该场所与权限时保留并说明必要性 | 真实职业技能课程中的原生场所、工具和责任 |
| “记录仅在浏览器、不上传、不关联身份、清理会丢失”等正常机制说明 | 从开场、场景和记录页删除；内部规则留在制作资料，界面直接提供当前进度及实际导出/删除操作 | 真实数据使用需决策时的说明、实际保存失败和删除确认 |

按钮用“标出这一段”“提交修改”“回到演示台”；状态用“批注已保存”“画面未加载，重试”。具体反馈可写“你用了起点的高度。再比较这两点的高度差”。示例只说明写法，实际反馈仍按本课证据与任务规则编写。

不通过反常数字、刻意不对称、强制深色、磁吸按钮、自定义光标或不停运动来制造设计感。布局的差异应能说明它如何帮助本课观察、阅读、比较或修订。

## 实现后的品质闭环

1. **建立基线**：已有页面记录版本、视口和关键状态；新课记录设计契约与候选页面。找出最影响学习动作的布局、可读性和状态问题。
2. **先改结构**：修正对象尺度、资料阅读、主次动作、遮挡和移动端排列；按任务保留必要信息。
3. **检查实际操作**：正常作答、主要错误、求助、修订、待审、返回和恢复可运行，操作结果和记录一致。
4. **完成细节打磨**：统一字体、间距、边界、图标、文案、焦点和有用途的动态；已确认内容按原范围核对影响。
5. **全量组装后复验**：使用正式媒体与实际最长内容重新检查。小样通过不能代替全课，样式修改后的旧截图不能代替新证据。

截图覆盖开场、主要舞台、核心资料/教具、主要错误与修订、结课，以及本课风险状态。可合并相同版式的证据，但不同布局、内容长度或媒体构图逐项核对。每份证据记录本版入口、版本或文件哈希、视口、状态、动作及结果。

实际浏览器至少覆盖：

- 桌面1440×900与手机390×844基线，以及目标设备所需横屏、窄屏和触摸。
- 200%文字/页面放大；普通阅读内容在320 CSS px宽度能重排。图表、空间教具等必要二维内容可局部缩放或滚动，例外不扩展到周围正文，按 [WCAG 2.2 重排说明](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)核对。
- 键盘进入、操作和退出工作面，焦点可见且不被固定操作条盖住；触摸目标沿项目44px基线检查相邻误触。不能只验 hover。
- 长题干、长字幕、多条依据、缺项、禁用原因、真实加载/失败、存储失败、静音、减少动态效果和刷新继续。仅适用于本课的状态必测；无异步工作时不造加载动画。
- 媒体实际首帧、中段、结尾和交互开放帧的裁切/锚点；换屏后角色、关键对象、字幕和工作面保持关系。虚拟键盘不遮住输入、错误或提交，资源加载不使教具和操作跳位。

问题分为阻断、需修复和建议，并附位置与学习影响。必需内容不可读、操作不可达、状态丢失、必需媒体故障后仍推进，或已声明主动等价路线未验收，均阻断 `functional_accepted`。已授权的可逆修复持续完成；建议取舍写理由，不追加人工签核。

`verification.md` 分别链接静态结构结果、实际浏览器操作、设计审阅结论和未执行项；将本版 `page-design.md` 与相关验收记录登记为生产清单证据。区域校验通过不能证明页面美观，截图不能证明操作可靠，设计审阅也不能证明学习效果。
