# 体验设计：让内容在参与中变得可感知

先明确本课希望学习者进入怎样的情境、注意哪一关系、在怎样的观察和行动中逐渐理解。按[内容与语境](content-and-context.md)核对来源，再设计体验；不用地点皮肤包装无关流程。

## 内容到体验

| 设计决定 | 写成可制作内容 |
|---|---|
| 核心理解 | 哪个现象、词句、空间/因果关系或人物处境值得亲历；依据与边界是什么 |
| 体验承诺 | 学习者将站在哪里，看见/听见什么，能接近和参与什么；不只写“沉浸感强” |
| 关键感知 | 哪个细节、声响、对照、尺度或变化使关系可察觉；注意点与停留时间 |
| 主动参与 | 点击查看、靠近、视点切换、跟随、操作、对话、自然选择、阅读中哪些动作有意义 |
| 现场回应 | 对象、人物、环境或信息如何回应，怎样带回同一事件自然接续 |

不是每段都要操作；安静观察和聆听也可承担内容。可选细节不要求全部点击。选择的后果应在世界中看得见，不要求所有选择分叉整段剧情；固定叙事可接纳局部自主探索。

## 完整主稿

先用当前内容写完整经历，包含入口、对象含义、实际台词/可读资料、声画、场景变化、参与、回应和结束。把语义正文与规则放入scene-plan.learning，编译为可读experience.md供确认；后续只维护一个语义来源，使用相同标识引用。复杂课程可拆源文件，但不能多份手工重述同一互动。

初次进入不假设学生认识人物、地点或符号。通过现场、台词/旁白和一次低门槛行动建立“这里是什么、我能做什么、为何值得看”；不统一套长简报或危机。独立代表场景也补足其最小背景。结束让经历与核心内容回响，可自然重看或带走观察记录，不安排考试或成绩页。

## 不同参与的完成含义

观察的关键事件实际呈现，可进入下一段；探索可随时退出并保留状态；对话/自然选择按真实回应继续；对象操作依当前世界规则变化。阅读保留位置。推进规则只能是这些现场条件，不引入隐藏的正确答案门。界面中的“继续”按内容自然命名，不显示后台验收/评分术语。

教师/制作者的内容正确与质量检查仍执行，学习者的体验不被改造成诊断题、引导练习、独立考试或反复答对流程。真实走访按[体验观察](experience-review.md)进行。
