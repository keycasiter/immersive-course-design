# 规则与数据归属

| 内容 | 唯一归属 | 派生或核对 |
|---|---|---|
| 学习体验、来源事实、人物/对象含义、事件/参与及自然接续 | scene-plan.learning；[场景合同](scene-contract.md) | compile_experience生成可读主稿与运行索引 |
| 共用画风与代表场景表现约定 | scene-plan.presentation | 代表场景确认与本版视觉审阅 |
| 生成/求值入口、运行绑定、依赖和资源 | scene-plan.implementation与resources | 当前源码/资源快照及实际制作检查 |
| 当前阶段、两次确认、实际文件与验收结果 | [生产清单2.0](production-and-version.md) | validate_production核对真实绑定与覆盖 |
| 运行状态、时钟、检查点与恢复 | [运行契约](runtime-contract.md) | 状态控制器及当前应用的实际运行 |
| 学科/语境和情境选择 | [内容与语境](content-and-context.md)、[体验设计](experience-design.md) | 内容审阅，不由脚本判定教学优劣 |
| Three.js造型、材质、渲染与动画技术 | threejs-anime-short | 本Skill的[交接](spatial-production.md)，不重复维护技术手册 |
| 源文件/权利/隐私与等价路径 | [来源与资产](sources-and-assets.md) | 本版资源与治理记录 |
| 真实体验验收 | [验收](validation.md) | 当前文件绑定的图像、操作、声音与命令证据 |

文档路由不另造schema。模板字段由合同拥有，脚本检查机械条件；语义、听感、质感和实际感受由相应真实审阅负责。用户决定优先；同级规则冲突先记录并解决再制作相关部分。
