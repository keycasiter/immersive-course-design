# 空间学习生产：从教学关系到可操作的场景

导航：[路线与分工](#路线与分工) / [教学和学科规格](#教学和学科规格) / [结构与画面](#结构与画面) / [生产步骤与依赖](#生产步骤与依赖) / [运行与学习证据](#运行与学习证据) / [放行与取舍](#放行与取舍)

用于实时3D、程序动画、结构/变量教具和混合课程。它是课程与视觉制作的交接规则；课程状态、澄清/内容/Demo门禁、学习评价和人工确认仍以主Skill及[生产清单](production-manifest.md)为准。方法维护不启动课程或试渲染。

## 路线与分工

| 路线 | 适用条件 | 权威制作源与成本 |
|---|---|---|
| 程序化 | 精确几何、规则变化、结构关系或受控变形能编码；目标画风可由所选团队实现 | 规格、生成/求值源码、参数和测试。便于变体和状态重建；复杂有机造型仍需设计、拓扑/变形能力，代码多不保证细腻 |
| DCC资产 | 雕刻/扫描、复杂纹理/绑定、外部编辑交接更适合 | 编辑源、纹理、绑定/动画和实际导出；有资产制作与版本同步成本，不因GLB完整就自动好看 |
| 混合 | 精确规则与复杂外观分别需要两条路线 | 同一单位/坐标/锚点、规则所有者与资源版本；避免渲染/判定各维护一套近似模型 |

实时页面与渲染视频是交付形态，程序化/DCC是制作路线，二者不要混为一轴。线性成片可作为课程示范，但独立观察、操作、取证和反馈仍需具体设计。没有必要的3D不制作，二维精确图解也可成为正式教具。

在当前技能目录读取`threejs-anime-short`：

| 当前难题 | 读取其参考 | 本Skill交付给它什么 |
|---|---|---|
| 文字落成几何与材料 | asset-craft、procedural-systems | 对象结构、比例/依据、单位、可变项、不变量、目标景别 |
| 制作顺序与文件交接 | production-workflow、production | 镜头/事件、接口、独占文件、上游就绪条件、教学完成规则 |
| 光色、PBR/绘画与多遍 | rendering-choices、render-contracts | 哪些关系必须看清、标注/测量约定、已定画风和像素预算 |
| 姿态、状态与规模 | motion-and-scale | 允许操作、变形后表面锚点、时间与状态重建、设备范围 |
| 技术与画面验收 | validation | 核心镜头标准、学科检查、交互路径及证据范围 |

从当前技能目录读取技术Skill，路径不写死。未安装时仍完成课程设计和学科规则规格；制作阶段说明能力缺口，用已授权且达到目标/品质的可用路线，不能静默降低交付。技术Skill不决定学习目标、不更改评分标准、不自动获得发布/付费权限。一个执行者可顺序承担职责；多Agent依当前授权和工具规则，不为“多部门”形式启动协作。

## 教学和学科规格

先形成[场景计划](spatial-learning-contract.md)，每个场景关联真实蓝图ID：

`学习目标 → 信息缺口/判断 → 学科规则 → 可操作对象 → 可见结果 → 解释/作品证据 → 针对性反馈与再做`

看完动画、任意旋转模型或反复试选不等于完成这条链。选择预测、比较、测量、构造、证据选择或解释中有目标价值的动作；依[教学设计](instructional-design.md)决定示范先行或先尝试，不把“预测—观察—解释”固定为所有内容的唯一脚本。

| 规格 | 必须明确的关系 | 检查方式 |
|---|---|---|
| 依据与真实性 | 来源支持什么；公式、结构、史实、设计推断与情境创作分开 | 核对来源、内容边界与未确定项 |
| 状态与输入 | 单位/坐标/尺度、参数范围、操作约束、初始状态和输出 | 边界/非法输入、典型状态与恢复 |
| 不变量 | 面积/数量/连接/比例/守恒或程序前置条件，按学科选择 | 可失败测试及适当误差；浮点容差由单位/用途推导 |
| 表示与近似 | 视觉变形、剖切、抬起、放慢、投影或简化在哪些区间使用 | 显示依据和含义；测量/评分使用正确模型，不从透视截图估值 |
| 教学反馈 | 什么证据能区分正确、误解、偶然和有帮助完成 | 首答、帮助、修订和独立应用分别记录 |

数值例子不是一般证明；视觉示意不是物理仿真。证明或机制说明需把条件、关键推理和结论对应到可观察变化。显示值、标签、对象变换与判定从同一求值模型派生，禁止分别硬编码导致“图对、数字错”。

## 结构与画面

先固定这一教学段的注意点、目标视口/景别、允许机位、对象占幅、标签/单位、主光/色彩和动作窗口，再实现生成器。自然语言负责描述目标关系；实际生成/更新规则把它落实成顶点、法线、材质、姿态和相机数据。

| 层 | 要求 | 常见误判 |
|---|---|---|
| 主形 | 轮廓、比例、空间层级、投影和主次清楚 | 多加表面噪声补错误轮廓 |
| 中层 | 真实厚度、连接/关节、截面、材料分区或结构层次服务教学对象 | 随机装饰增加信息负担 |
| 细节 | 只增加目标像素可读且稳定的信息；密度/单位/颜色意义统一 | 顶点、纹理、灯数越多越好 |
| 光色与材料 | 主光揭示关系，接触/阴影有解释，材料有区别；图解可选克制unlit/风格材质 | 暗、泛光、描边或镜头晃动掩盖结构缺口 |
| 标注与镜头 | 标注跟随真实世界锚点，正反/剖面有声明；精确面积/角度比较采用适当正投影或明确透视边界 | 把漂亮斜视图当精确测量证据 |

“高品质”按教学可读性、造型/光色和时间稳定性共同判断。必要时用灰模、中性光、固定机位定位已发现的问题；不要求每次全套探针，不用无目标重复整镜渲染寻找风格。

## 生产步骤与依赖

| 阶段 | 就绪输入 → 实际产物 | 放行条件 |
|---|---|---|
| 教学与事件设计 | 来源、目标、画像 → 任务/反馈/独立应用、场景计划与页面设计 | 教学目标需要该对象和动作；按原设计门取得确认 |
| 规则与资产 | 规格 → 单一求值模型、参数约束、程序几何或DCC资产、锚点接口 | 学科/结构正确，标签和可见模型消费同一状态 |
| 核心镜头与操作闭环 | 可用资产、规则、机位/光色 → 最难代表性“观察/操作—后果—反馈/修订—返回” | 达到候选正式画质、运行/等价路径成立；按原媒体门确认，不只审漂亮静帧 |
| 扩展与组装 | 已确认制作契约 → 其余场景/反馈、共用字幕声音和版本资源 | 全量必需内容逐场验收，角色/对象/规则连续 |
| 运行与试学 | 本版实际入口 → CUA操作/目标视口、学习尝试、问题闭环 | 分别记录功能、真实试学和效果，不把阶段校验替代学习证据 |

小课程缩减产物篇幅和题材范围，保留必要教学质量；独立小样自带最小对象、术语、目标和操作背景。无人物的课程由可回应旁白/界面主持，不为了“沉浸”强加NPC或危机剧情。

关键依赖是规则模型→资产/标签/反馈、变形锚点→接触/FX、实际声音→字幕/cue、目标视口→细节/标注、学习完成规则→返回/推进。共享契约有唯一写入者；相机/LOOK/对象状态各有明确所有者。输入没就绪先补缺口，不让各模块各猜一套。

## 运行与学习证据

具体运行契约见[场景与状态](spatial-learning-contract.md)。求值不是只设置time uniform：姿态、几何、显隐、标签、FX、字幕及随机/历史状态都要能重建。动画可随机seek，不代表学习状态也能任意快进；预览/回顾与首次学习模式分别实现。

主媒体、操作、反馈和返回共用稳定对象/事件ID。切到局部任务先暂停冲突媒体，保存当前对象、输入、机位、时间/事件和焦点；恢复时核对版本，重建同一状态，保留首答与求助痕迹。声音由用户操作恢复，避免两段旁白叠加。

## 放行与取舍

| 证据域 | 能说明什么 | 不能替代什么 |
|---|---|---|
| 数学/学科与状态测试 | 覆盖的关系、边界、状态转换、可重复求值 | 内容依据、真实画面和教学有效性 |
| 原尺寸帧与连续片段 | 结构、光色、标签、动作/遮挡和闪烁 | 实际点击、触摸、恢复或学习者理解 |
| CUA/MCP真实目标页面 | 已执行的控制、任务、反馈/恢复和可见状态 | 未测设备、全片声音听感和学习效果 |
| 真实试学与目标评价 | 在记录条件下的困难、改进与独立表现 | 全体学习者或其他学科的普遍效果 |

运行证据只保存目标视口，不使用桌面整屏截图；导出帧可作作品证据，不冒充CUA。缺工具/锁屏时保留具体未覆盖项。连续两次同层修正仍失败时重查表示、前置设计和根因，避免继续穷举。风格化可降低不必要的写实成本，不能删掉任务所依赖的结构、因果与可读性。
