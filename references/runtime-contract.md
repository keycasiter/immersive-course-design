# 实时场景、参与与恢复

Three.js负责渲染、命中与动画，应用负责世界规则、场景状态、DOM与媒体。完整 `scene-plan`提供统一对象/事件/互动ID；可复用[轻量控制器](../assets/scene-runtime.mjs)并实现adapter，也可在现有框架中保持同等契约。控制器不自动创建网格、命中、声音、存储或资源生命周期。

## 状态与所有者

| 状态 | 内容与写入者 |
|---|---|
| 体验状态 | 当前场景、实际已呈现事件、对象状态、自然选择/对话与可选查看；控制器按世界规则接续，不维护成绩/掌握率 |
| 演示时钟 | 场景/局部声音的连续时间；有主导音频时与其同步，tick/seek不自动完成必需事件 |
| 视图 | 相机/target/zoom/剖面/选择、阅读位置和焦点；改变视图本身不表示理解 |
| 音频 | 用户操作后启用；暂停/局部对话/返回与恢复有唯一所有者，避免叠音 |

对象/对话/视图patch须为有限、可序列化数据，网格和DOM实例留在应用。规则求值器输出供可见几何、数值/标签与对象响应共用。需要历史的仿真按固定种子/步长或检查点重建，不只设置time uniform。

## 从计划接到实际场景

| 顺序 | 实施动作 | 完成条件 |
|---|---|---|
| 初始化 | 加载完整计划与资源，建立ID到网格/DOM/声音的映射，创建控制器与adapter | 首场合理等待；构造器立即调用`onSceneEnter`和`evaluate`，回调不依赖尚未赋值的controller变量 |
| 输入 | 鼠标/触摸/键盘统一调用`act(interaction_identifier,payload)`；adapter校验本课参数/前置条件并返回patch | 同一动作走同一规则；无效动作不会产生伪造的现场变化 |
| 求值 | `evaluate(state)`从状态与时间完整更新网格、世界矩阵、标签、显隐、人物、FX、字幕与DOM | seek/返回/恢复得到同一状态；不重复创建资源或播放音频 |
| 呈现 | 主应用在相应画面/声音真实呈现后调用`markEvent`；异步结果核对仍属当前场景/动作 | 点击、动画中途、资源失败不提前记完成；`emits_event_identifier`只声明关系，不自动触发 |
| 接续 | 按计划检查真实必需事件并`continueTo`，保留可选查看状态 | 只能进入已声明后继；终场退出由应用处理，不制造不存在的场景ID |

`act`返回的patch按顶层替换，不作深合并；改一个对象时保留 `state.objects` 中其他对象。`evaluate`会在构造、act、markEvent、时钟和恢复时调用，因此只求值，不在其中调用 `markEvent`造成递归。呈现确认由主应用协调，针对同一已呈现事件只回报一次。

## 控制器与adapter接口

| 接口 | 责任与边界 |
|---|---|
| `createExperienceController(plan,adapter)` | 输入完整计划，不能仅传编译出的ID索引；初始暂停 |
| `getState()`、`act(id,payload)` | 读取状态快照；校验当前场景的已声明动作/目标；调用adapter并完整求值 |
| `markEvent(id)`、`continueTo(id)` | 记录本场事件，按已声明接续和真实必需事件推进；不由渲染回调自动推进 |
| `tick(seconds)`、`seek(seconds)`、`pause(value)` | tick只在非暂停时推进；seek定位局部时间；应用提供明确的开始/继续入口 |
| `snapshot()`、`restore(snapshot)` | 捕获视图并保存通用状态；核对版本/ID后恢复暂停状态，回调重建场景与视图 |

adapter实现 `evaluate(state)`、`act(action,payload,state)`，按需实现 `captureView()`、`restoreView(view)`与`onSceneEnter(id,state)`。act只能返回objects/dialogue/view/notes；语义场景与事件由控制器拥有。实际接线见[实施示例](worked-example.md)，纯控制器单元测试不证明画面或命中已完成。

## 检查点、失败与重建

检查点包含合同/体验版本、scene/time、已呈现事件、对象/对话与视图。通用控制器核对版本与合法ID；应用在restore前另核对自定义参数范围/枚举等世界规则，避免非法状态已写入后才在绘制时出错。同一输入/种子/时刻应稳定，恢复以暂停状态落地，声音由用户继续。未知版本或破损记录提供明确的安全重置入口，不悄悄套用旧经历。

resize/横竖屏同步投影、renderer、世界矩阵、命中与文字安全区。WebGL丢失先暂停并保留状态，再重建资源/投影/标签后恢复；事件监听与几何/材质/媒体均由应用释放。重试失败时提供已验收的同目标路径，不能跳过必需内容。

网页布局与键盘/触摸/静音/低动态见[页面与等价参与](page-and-accessibility.md)。真实应用按本课实际互动类型检查可达、响应、返回、重看、阅读位置及中断恢复，证据按[验收](validation.md)记录；自然对话不转成判分或首答锁定。
