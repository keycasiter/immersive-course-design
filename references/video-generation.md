# 课程视频生成与故障规避

课程视频默认按[通用视频生产系统](video-production-system.md)建立能力矩阵、参考包、真实声音时间轴、逐镜与生成单元及时间线。导演/表演和接缝执行[导演与连续性](video-direction-and-continuity.md)，正式成片执行[时间线与实际验收](video-timeline-and-quality.md)。本文件保留已验证工具行为与故障处理；不能只写一条提示词就省略生产流程。每次生成先核对当前 TRAE 工具目录和本机 TRAE CLI（若安装），记录真实工具标识、可用模型和计费；历史工具验证不能证明本轮接口可用。CLI 存在不等于 `GenerateVideo` 可调用，需确认该 CLI 会话中的 MCP 已就绪并实际暴露目标工具。正式视频生成固定使用 TRAE `GenerateVideo`；工具不可用时停在原型/制作计划状态，不静默切换 Seedance、Wan 或其他视频后端。只有用户明确修改项目生产配置后，替代后端才可作为新路线重新做能力小样和验收。
生成成功只表示取得文件，不代表人物连续、事件可用或能够进入互动。
异步提交、排队、下载失败、取消、预算与共享GPU统一按[媒体任务运行与恢复](media-job-execution.md)记录和恢复；先查原任务，不把下载错误当作重新生成的依据。

## 推荐输入顺序

1. 先用不含真人身份的角色设定图固定服装、年龄、体态和随身物件。角色图应明确为虚构人物，可采用绘制设定稿、非真人3D角色或经授权的课程资产。
2. 写实课程先制作或生成摄影级实景定帧，锁定真实砖石、木材、织物、肤质、空气透视和自然光，再用它作为视频主视觉参考。Blender场景图只用于空间方位、机构尺寸、动线和物件位置校验；除非课程明确采用CG风格，不能把低精度Blender视口、全景渲染或程序角色直接用作首帧、角色参考或主风格参考。
3. 先确定实际对白/旁白的完整声音与动作覆盖，再写分镜与首尾状态。按提供方真实时长档位编译生成单元；单镜默认一个主要相机运动，人物动作按真实事件顺序。支持多镜头的单元可有多个 shot，输出不重复装配；等待帧只用于已说完且动作到位的互动入口。
4. 精确中文、数字、表格和学生批注不交给视频模型生成，保留无字纸面，页面运行时再确定性叠加。
5. 画内角色说话时必须有与实际对白同步的口型。优先使用支持固定声音参考的原生有声生成，或使用固定配音驱动口型；不能让闭嘴等待的人物承载画内对白。视频内对白和视频外回应必须沿用同一角色声线，知识旁白另用独立声线。原生声音可以保留为角色候选，但不能仅凭相同声音描述认定跨次生成音色一致。
6. 若原生生成器不能接收声音参考，先在同一源片录制主线与一条完整反馈，保留该真实源声作为候选参考；它只验证同源衔接，不证明与旧声库匹配或能够稳定扩展整课。后续通过受支持的固定参考生成或授权录音扩展，重新验收身份与口型。不能把生成后单纯替换音轨当作口型同步。
7. 保留对白、旁白、环境和动作分轨用于制作与互动控制。正式交付的每段线性视频必须把已验收的人声与环境/动作声混入MP4；网页分轨不能代替成片音轨。互动反馈作为同场画外声时可停在自然等待帧，须建立角色所在位置；若反馈画面表现角色正在说话，也要有同步口型。

## 写实风格防漂移

- “历史写实”“真人比例”文字不足以抵消CG参考图。参考图的材质、灯光、建筑重复度、角色脸和镜头透视会成为更强的风格条件。
- 摄影级主参考应具有不规则旧砖、潮湿或磨损变化、真实木纹和铁锈、自然肤质、布料重量、适度景深、空气层次和非对称生活痕迹；避免平直贴图、重复窗格、空旷游戏地图、统一边缘高光、塑料皮肤和3D角色设定板。
- 角色身份需要连续时，先用同一摄影级角色定帧制作正面、侧面、全身和现场动作参考。非真人不等于必须使用3D人物；可使用明确虚构、无现实身份来源的摄影级合成人物。
- 每批先做一条含人物、环境、手部动作和稳定等待帧的代表镜头。接触表若呈现游戏过场、蜡像人物、CG院落或平直材质，整批停止，不用“后期调色”掩盖风格错误。

## TRAE GenerateVideo 已验证行为

2026-11-02在本项目实际验证：

- 同时传本地 `video_paths` 时，当前ToolHost返回
  `readBinaryFile: video processing is not available in this ToolHost build`。这是本地视频参考预处理能力缺失，不等于文本或图片生成视频不可用。
- 去掉 `video_paths`、只传本地图片参考后，请求能够进入模型。
- 传入疑似真人照片时，后端可能返回
  `InputImageSensitiveContentDetected.PrivacyInformation`。不要规避检测或反复提交该图；改用虚构角色设定图、Blender角色、无人物空景或纯文本描述。
- 仅用无真人的Blender院落图和虚构角色文字描述，已成功生成1280×720、24fps、10.08秒课程样片。
- 即使提示词要求无声，返回MP4仍可能包含AAC音轨。先判断实际声音内容。正确原生对白应保留并核对口型、正文与声线；错误人声需要重做或用固定声音驱动口型，不能只换音轨后声称完成。正式线性视频不能以静音MP4交付。

先做一条最难镜头的图片参考小样。图片参考成功后，再按同一输入契约生产其余镜头；不要在未验证的ToolHost中把本地视频参考批量提交。

2026-11-03在本项目追加验证：纯文字输入、明确虚构人物、要求标准普通话同期对白，成功取得10秒提问和15秒提问/反馈原生有声镜头。15秒源片的两条完整对白可分别用于主视频与整句画外反馈。实际口型在说话时变化、说完闭嘴，精细同步仍待播放听审；服务返回不保证每次声线一致。新原生声音另登记候选，不自动等同已有固定声库；平台角标仍需按原分辨率检查。此前网络下载错误与一次安全检查失败没有证明原生中文有声能力永久不可用。

## 错误分类与处理

| 实际错误 | 含义 | 处理 |
|---|---|---|
| `video processing is not available in this ToolHost build` | ToolHost不能读取或预处理本地视频参考 | 去掉 `video_paths`，改用角色设定图、场景图或纯文本；不要据此宣布整个视频工具不可用 |
| `PrivacyInformation` / real person | 输入图疑似包含真人身份 | 停用该图；改用明确虚构且非真人来源的角色设定，不做检测规避 |
| per-request call limit | 本轮视频调用额度耗尽 | 本轮不再重试；保存镜头计划和已完成产物，下一轮继续 |
| 请求成功但人物/手/道具漂移 | 生成质量不满足事件 | 简化为一个动作；必要时拆成“放下对象”和“对象已稳定”两镜，不用长动作反复碰运气 |
| 请求成功且带原生对白 | 模型返回同期角色声音 | 核对全文、普通话、口型与角色声线；正确声音可保留，错误对白或身份漂移则重做；换成固定人声时必须同步驱动口型 |
| 人物闭嘴而音轨在说话 | 无声表演与对白脱离 | 停止将该镜头登记为画内对白；重新生成有声表演或实施音频驱动口型，不能用字幕掩盖 |
| 写实提示词却呈现游戏或CG质感 | Blender/3D角色图成为强主参考 | 停止整批；取消该图的风格/首帧地位，先生成摄影级实景与虚构人物定帧，Blender只保留为空间校验 |

## 每镜验收

生成后必须：

1. 用 `ffprobe`记录时长、分辨率、帧率、编码和是否含音轨。
2. 每2秒抽帧制作接触表，检查人物数量、服装、脸、手、道具、文字、水印和空间方向。
3. 查看动作开始、接触、松手和最后等待帧。互动入口要求对象无遮挡、人物仍在场、至少约2秒稳定。
4. 核对角色是否参与当前对象，不能只有画外声或无关人物背景。
5. 保留已验收的原生角色对白，或以固定声音驱动口型，再与独立旁白和同场环境/动作声混音；用 `ffprobe` 确认正式MP4存在音轨。实际播放检查开口、闭口、停顿和完整台词，逐句核对字幕；抽帧或存在音轨不能证明口型同步。静音视频只可作为中间素材，不得登记为正式成片。
6. 登记提示词、参考图、实际文件、SHA256、生成错误和重做原因。原始生成、整理成片和课程可用分别记状态。
7. 用视频生产校验器检查实际声音与源片覆盖、源区间重复、解码、流终点及疑似冻结和发声交叠。正式真人讲话/行动的时长缺口不能用尾帧冻结、循环、倒放或数码缩放补齐；补真实动作/对象/反应镜头、自然话轮分段或已验证的延伸，不裁声音或加速台词。静态教具、真实微动作和互动等候按具体区间及用途核对，不做全片“必须恒动”的判定。

已有带水印、身份漂移或错误文字的视频只作构图与动作参考，不登记为正式成片。不得通过裁切或遮挡水印把参考素材冒充无水印正式资产。
