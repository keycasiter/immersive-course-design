# 内容、语境与学科转译

学习理解围绕真实内容发生。先核对主题、版本、来源、先修和内容边界，区分来源事实、合理推断、解释分歧、情境创作和未确定项。只有主题时提出具体体验设计，不声称对齐不存在的教材。

## 有解释力的语境

对作品、人物、事件、地点、理论或发明，选择能回到核心内容的背景：形成条件、人物处境、地点与材料、前因/后果、典故互文、前驱与转向、传播/接受和影响边界。按当前理解需要定向查可靠原件、机构/博物馆、学术或可信教育来源，保留可定位引用与实际观察范围；检索摘要只用于找来源。

背景应在当前对象或疑问需要它时出现，并改变后续观看、聆听或理解。可以用人物所见、旧版本、同一物件的前后状态和不同尺度引出，再回到原对象。资料容量按解释力选择，不固定关系数量、人物数或场景数。因果/影响有作用路径，不把时间先后或相似直接当证明；争议与创作明确说明。

## 按内容选择可感知关系

| 内容 | 可考虑的体验机制 | 保持的边界 |
|---|---|---|
| 语言与文学 | 声音/节奏、意象、叙述视点、词句与场景对照、语境揭示后的重看 | 景象服务文本，人物生平不替代文本依据；画面不是作者唯一意图 |
| 数学 | 单位与同整体、分割/重组、连续变化、空间和符号对应、可见推理 | 数值例子不等于一般证明，透视/视觉近似不决定精确关系 |
| 科学 | 条件变化、可视化不可见过程、剖面/尺度、系统反馈、现象与模型往返 | 模型假设、误差与适用范围明确；展示与真实观测区分 |
| 历史与社会 | 当时信息/权限/约束、不同人物所见、器物/资料、时空尺度与后果 | 不让学习者“改变真实历史”；对白/人物合成披露为创作，保留来源立场 |
| 工程、艺术、音乐与动作 | 部件/过程、材料、版本变化、节奏辨听、受限行动与作品自然回应 | 形状不证明机构正确，动作/因果有依据；创作不化为标准答案 |

这些是设计候选，不是固定学科配方。先识别当前内容中难以感知的关系，再选择主表征和必要辅助。2D/2.5D/3D按用途配合，主场景由Three.js编排；文字、公式和资料保持可读。不为证明使用3D额外制作二维试片。

缺资料时有限检索并记录未知，不由生成外观补成事实；不把未核实判断写成确定知识。真实学习者理解的变化需独立观察，不能从浏览量或操作次数推断。
