# 来源、资源与治理

内容来源支持的事实、解释推断、情境创作和未核实项分开登记。每项采用的原文、数据、身份、年代、结构或机制有可定位来源与支持范围。私有部署、账号、凭证不写入可分发计划。

程序化生成器是制作源；几何、材质和状态可运行时产生，不必保存模型文件。文字/图片/纹理/声音/字体/资料按实际需要登记资源ID、文件或生成来源、版本、权利依据、隐私审查、披露、保存策略和等价路径。无需为未使用的外部资产补假任务或假文件。

当前正式文件核对格式/解码、依赖、校验值和用途；生成成功只代表任务结束。若使用外部生成服务，在本轮核对实际工具、输入/输出能力、成本与授权，保存请求/任务标识和实际结果；恢复先查原任务，避免下载失败导致重复付费。仅声明工具名称不证明可用。

学习记录默认最小化本地保存，只记录恢复与体验所需状态。可选查看不作为打卡，观看/点击不换算掌握。上传、身份关联、保存期限、导出和删除在真实操作入口披露；内部验证信息不常驻挤占场景。可感知的创作或近似边界在相关内容处自然说明，后台制作过程不进入台词。

正式资源的全部依赖进入当前文件快照。压缩/简化后复查近景、关键关系、声音与目标设备；许可/隐私和视觉/教学准确性分别验证。
