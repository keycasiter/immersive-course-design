# 从知识到沉浸体验的推导

本参考负责把课程内容推导成沉浸体验，不提供可直接换词复用的剧情、角色、世界或页面模板。核心原则是：

> 抽象方法，不抽象产物；固定决策过程，不固定具体内容。

课程案例、用户举例和既有 Demo 只能帮助识别设计约束，不能直接成为新课程的世界观、角色、开场、任务、互动或视觉母版。推导结果写入 `course-design.md`、`experience-blueprint.md` 和既有矩阵，不新增一套平行 schema。

## 一、先建立教学源头

开始构思世界或画面前，先从权威内容和学习者条件写清：

1. 学习者最终要独立完成什么；
2. 完成表现依赖哪些知识对象、关系、条件或程序；
3. 哪些是已知基础，哪些未知，哪些必须在课内建立；
4. 什么行为或作品能证明学习者已经形成目标能力；
5. 哪些误解、边界或错误步骤必须被显露；
6. 哪些内容需要讲解、示范、引导练习、撤除帮助和新情境应用。

如果目标、证据或未知基础仍会改变教学顺序，不得先定城堡、实验室、任务身份、第一人称镜头、3D 对象或热点数量。

## 二、完成一条可追溯派生链

每个必需目标都沿同一条链推导：

```text
学习目标与未知点
→ 知识对象、关系与边界
→ 知识点难点、教学机制与表征桥梁
→ 学习者必须完成的知识动作
→ 可观察的学习证据
→ 体验关键时刻、视角与感知节奏
→ 适合承载这些动作的事务或世界
→ 学习者的视角、权限与行动理由
→ 视频主线中的事件、对象和变化
→ 局部互动及其进入、反馈、修订与返回
→ 撤除帮助后的新情境独立应用
```

每一箭头都要写出理由。知识难点、教法比较和体验方式按[学科教学选择](subject-pedagogy.md)先完成，不能由互动控件倒推。教学作用追溯到上游知识动作和证据；独立体验作用按[内容质量](content-design-quality.md)的 `experience/both` 登记具体进入、空间、情绪、注意或连续性增量，再按[沉浸评价](immersion-evaluation.md)落实到声画决定与判据。仅称“更沉浸/更有冲击力/技术上能做”不足以保留。无教学或可观察体验作用的元素删除或简化；纯体验元素不得独有承载必需知识。

## 三、选择世界，而不是套世界

先生成至少两个结构不同的承载候选，再按下列条件比较，不从用户例子中直接选一个换皮：

- **教学贴合**：世界中的正常事务是否天然需要目标知识，而不是把题目硬塞进剧情；
- **零背景可进入**：陌生学习者能否从可辨认对象、状态或行为理解正在发生什么；
- **行动必要性**：学习者为什么必须观察、比较、操控、判断或修订；
- **结果可感知**：知识动作是否会改变对象、关系、读数、解释、作品或后续状态；
- **主线连续性**：同一对象、问题、记录或结果能否贯穿视频、互动、反馈和结课；
- **认识诚实**：模拟、简化、创作、推断与来源事实是否清楚分开；
- **制作可行**：现有时长、设备、媒体能力和无障碍路线能否支撑。

先比较教学贴合与具体体验增量，选择最能承载两者的候选；两者相当时才用较低复杂度决胜。复杂度优化保留运动、节奏、空间、共同关注等已说明的体验作用。真实工作现场、日常事务、抽象模型、对象内部、历史重建、创作空间或无角色观察都可以成立；本 Skill 不预设某一种世界更沉浸。

## 四、让陌生学习者自然进入

默认学习者没有当前世界的背景，但可能拥有一般生活经验或部分学科基础。开场先建立理解和参与，不先播放一段独立介绍片。

首个有效行动前，体验必须逐步回答：

1. 我看到的是什么，它通常处于什么状态；
2. 此刻发生了什么变化、缺口、委托或值得解释的现象；
3. 为什么需要我关注，而不是由旁白直接给结论；
4. 我现在能做什么，不能做什么；
5. 我的动作会留下什么可见结果；
6. 不理解术语、工具或情境时，支持从哪里取得。

进入可以从行进、观察、交接、正在进行的工作、对象变化或自然回应开始，但不得把第一人称运动、事故、召唤、授予身份或 NPC 简报固定为开场公式。视频负责让学习者在连续事件中到场；必要说明与对象、动作、对白和字幕同时建立，不把“先看介绍，再进入互动”当作默认结构。

## 五、视角和角色由知识动作决定

分别决定叙事尺度、镜头视点、学习者权限和课程身份，不把它们绑定：

- 需要空间定位、身体尺度或现场判断时，可优先采用第一人称或近身视点；
- 需要比较系统、时间跨度或多方证据时，可采用宏观、纪实或多视点；
- 需要观察内部机制时，可采用对象跟随、剖面或模型视点；
- 不需要社会身份时，不创建虚构角色，直接让对象和系统回应学习者。

角色的教学作用看它改变的动作、信息权限、责任或反馈关系；体验作用看可感知的共同关注、情绪或现场联系，按内容质量 owner 登记并取证。称号、服装、头像和欢迎语本身不构成参与。第一人称只是一种视点，不自动等于沉浸，也不能遮蔽学习者需要比较的证据。

## 六、把视频做成事件主线

视频不是知识介绍容器，而是课程世界持续发生的时间线。每个 Beat 至少承担一种不可替代作用：

- 建立空间、对象或正常状态；
- 呈现无法由静态文字等价表达的变化、过程或关系；
- 让学习者看到行动前后的可比较状态；
- 把局部互动放回同一事务、对象和时间位置；
- 为后续解释、练习或独立应用保留共同证据。

不要求视频连续播放到底。可在关键帧、对象出现、状态变化或证据成立时暂停并开放互动。互动完成后必须回到同一事件及其更新后的对象状态，而不是跳入独立题库。

## 七、按教学需要决定互动深度

先确定知识动作与体验作用，再选择能完整承载两者的表面；以下是实现候选，不替代前置学科教法选择：

- 只需辨认或定位时，使用对象热点、标注或有限选择；
- 需要比较关系时，使用并置、叠加、时间拖动或条件切换；
- 需要理解机制时，允许改变变量并观察确定性结果；
- 需要空间结构时，使用二维分层、多视图、360°或 3D 中成本最低且证据充分的一种；
- 需要程序能力时，让学习者执行、检查和修订步骤；
- 需要论证或创作时，提供证据结构、作品状态、量规和人工或自评责任。

2D、3D、360°、模拟、卡片和文档层都是局部学习表面，不是课程类型。技术复杂度不得替代知识深度。热点必须指向当前画面对象和行动，不能只是打开一张与场景脱离的题卡。

## 八、闭合教学循环

沉浸不改变教学责任。每个必需目标都必须在适当位置完成：

```text
必要背景或诊断
→ 讲解或示范
→ 学习者执行关键动作
→ 针对对象、关系、条件或步骤的反馈
→ 保留原状态进行修订
→ 逐步撤除答案性帮助
→ 使用新材料或新条件独立应用
```

先尝试还是先示范由先修、风险和诊断价值决定。第一动作可以是低风险观察或预测，但不能要求学习者猜尚未教过的结论。完成剧情任务、触发动画或在帮助后答对，都不能替代独立应用证据。

## 九、防止参考案例复刻

使用任何课程案例、截图、用户描述或既有原型时，执行以下转换：

1. 只提取它解决的通用问题、约束和有效机制；
2. 删除案例中的学科名、地点、角色、道具、剧情、视觉母题和技术组合；
3. 从当前目标重新生成知识对象、行动理由和至少两个承载候选；
4. 逐项证明最终方案来自当前课程材料，而不是参考案例的名词替换；
5. 做相似性审查：若世界、身份、开场、任务顺序和互动组合仍能与参考一一对应，重新推导。

可以复用的是决策原则、状态责任、验收方法和技术契约。不能默认复用的是具体世界、角色、冲突、镜头、道具、任务、热点、奖励、视觉风格和交互组合。

## 十、四道准出门

进入详细脚本、分镜或页面实现前，必须同时通过：

### 派生门

每个世界元素、视频事件和互动都能追溯到知识对象、学习动作、必要定向，或内容质量 owner 认可且有具体判据的独立体验作用。教学派生与体验取证分别成立，必需目标仍须闭合教学循环。

### 进入门

零背景学习者能理解当前对象、正常状态、行动理由、权限、第一动作和支持入口；开场不是独立介绍片加任务页。

### 教学门

必需目标有适当的讲解/示范、练习、具体反馈、修订、帮助撤除和新情境独立应用。

### 非复刻门

方案通过候选比较从当前课程推导；不存在对参考案例世界、角色、剧情或交互组合的一一换皮。

任一门未通过时，只能继续澄清或重新推导，不得以视觉冲击、媒体数量、技术复杂度或页面完成度代替。

## 审阅问题

1. 若删除世界名称和角色称号，当前事务仍然需要这些知识动作吗？
2. 学习者为什么此刻行动，理由来自对象和状态，还是来自一句命令？
3. 视频是否在推进事件和证据，还是只在讲解课程介绍？
4. 互动是否改变或检查真实知识对象，并返回同一事件状态？
5. 新手是否在被要求作答前获得了必要教学？
6. 帮助撤除后，学习者是否在新材料或新条件下独立完成？
7. 当前方案能否说明每个关键决定来自哪条课程内容和学习者条件？
8. 与参考案例相比，是否只保留了方法，具体世界和体验是否重新生成？
