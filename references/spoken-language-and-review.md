# 可录制台词与口语审阅

用于所有课程的 NPC 对白、讲解、旁白及可听反馈；不以是否有剧情决定适用性。中文默认用清楚、自然的普通话，语气服从人物职责和已确认的课程风格。其他语言按本课语言审阅，中文例句不能充当其自然度依据。

把这一流程落实到既有课程稿、媒体计划和 `verification.md`，不新增许可门，不要求另装技能。教学可以直接讲事实、解释概念、演示步骤和复习关系；讲解员不必制造冲突、潜台词或悬念。

## 1. 写台词前，先确认听者与用途

为每段或一轮对白在设计说明中确认：

- 谁向谁说话，双方是什么关系；知识旁白面向哪类学习者。
- 听者在这条路径上实际看过、听过什么；当前哪项背景或概念仍陌生。
- 当前要讲清哪件事，或希望对方看、比较、操作、解释什么。
- 话里的“这里、这段、它、刚才”指什么；对象何时可见或可取得。
- 若是反馈，依据哪条实际输入、确定规则或审阅结果触发；接着让学习者做什么。

这些是写作依据，不能念进录音。人物声音来自关注什么、怎样解释、怎样对待新手和怎样回应；不靠每次重复口头禅。没有收到学习者回答时，不编造其问题、错误、情绪或理解程度；有依据的预写分支须登记触发条件。

## 2. 先说具体内容

直接写出主体、动作、条件和结果，让学习者顺着听懂。抽象概念先与本课对象或例子相连，必要时保留学科原名和定义。每段围绕当前要讲清的事展开，句子长短按语义与听感调整。

遇到以下写法，检查整段的表达意图并改写，不能只换同义词：

| 问题 | 改写动作 | 保留边界 |
|---|---|---|
| 否定一个听者未提出的说法，再用“还/更/而是”拔高 | 直接讲清对象是什么、谁做什么 | 对实际误解的纠正和有信息的比较可以保留 |
| “补上原因、让路线带着条件、把处境放回行动”等拟人或抽象搭配 | 说清发生了什么、为什么这样做，或请学习者解释哪一段 | 能帮助理解且说明了对应范围的类比可用 |
| “关系到活动、组织和补给”等名词堆叠，没有讲明关系 | 给明确主体和动作，解释各项在当前问题中的作用 | 必要类别、构成和专业术语不因并列就删除 |
| “接受材料检验、形成独立解释”等设计或评价说明 | 将方法说明放回设计文档；录音说实际要比较/写/改什么 | 推理方法本身是目标时可以教，但须有实际例子或步骤 |
| 每场以“这才是……”“现在……有了意义”收尾 | 结束在具体结果、已成立的关系或自然接续上 | 有学习用途的回顾、归纳和必要重复保留 |
| 逐条念身份、目标、路径、分工和支持 | 按听者当前所需写，并把信息分配到实际动作、对白和可读对象 | 首任务前必需背景、参与方式和最终产出仍须实际呈现 |
| 连续泛泛提问或“你可能会问”后自己回答 | 直接解释；要学习者回答时给明确问题并留实际窗口 | 主持者用于组织讲解的具体设问可以保留 |
| 所有回应都是夸奖、格言或能力宣告 | 回应可核对的输入，指出哪一处成立、还缺什么以及怎样继续 | 未经验证不得说“你已经掌握了”“我看懂你的全部解释了” |

不要用每句二十字、强制三句、固定长短交替或口头语配额控制台词。不要机械加“嗯、啊、其实、说实话、你看”，也不要改成网络梗、幼儿语、翻译腔或名人腔。动作和停顿只在指向对象、等待、换关注点或回应时使用，不插入无意义搬物来打断独白。

纪实讲解保持来源口径，角色不编造亲历、回忆、家人故事或历史人物原话。术语、公式、严肃内容和精确操作可以正式表达；自然口语不等于随意。

## 3. 单独审全部可听文本

初稿完成后，在分镜定长和配音输入前执行：

1. 从实际课程稿与蓝图列出主线及所有会发声的分支：开场、背景/概念讲解、示范、提问、结果成立、各主要误解、各层帮助、重试、返回、刷新/恢复、可选探索和结尾。局部任务只覆盖授权范围并注明排除项；全课不能只审代表段。
2. 按实际播放顺序提取纯台词，保留说话者和台词标识；把镜头、教学目标、评价标签和导演说明移到旁列。一个场景可分多个段落，条件不同的反馈分别审。以全部台词标识核对覆盖，不用场景数代替分支覆盖。
3. 先通读整段和相邻段，标出套话、含混指代、信息堆叠和全课重复结构。先确定这次要说清什么，再重写段落；只有局部确实独立时才只改一句。
4. 可用时读取 `humanizer` 并采用嵌入模式，执行标记、整段改写、事实复查与二次检查；最后仅回填课程台词。其文章去重复建议须服从必要讲解、检索练习、复习和无障碍重述，不自动删掉这些教学内容。
5. `ai-style` 可补充中文措辞判断，其规则各有文章作用域，不把它的句式检测宣称为口语验收。可借 `short-drama-write` 的说话对象、当前目的、回应与朗读方法；不套每轮争夺、秘密、权力后果等戏剧要求。
6. 外部技能缺失时，仍完整执行本参考的写前判断、具体表达、整段改写、下节不变量核对与朗读检查。不要为了审台词停下来要求安装，不声称执行了未读取的技能。

课程稿保存唯一权威正文及稳定 `utterance_identifier`。该标识是稿件与交接追踪键，可放在既有正文引用旁，不要求新增蓝图契约字段或迁移旧课。同一句跨文件复用时引用其精确位置；蓝图或制作格式必须内嵌文字时同步内容，保留同一标识。分镜标签、触发条件和设计说明不作为正文送入 TTS。

## 4. 改写后复核事实、教学与触发

将改写前后的意思逐项对照：

- 来源：主体、日期、地点、数字、单位、专名、称谓、引用、因果关系、范围和不确定程度。禁止为了具体而添加无来源的细节。要求逐字引用的原文保持原文，解释另写。
- 必需教学：定义、背景、条件、示范过程、推理和适用边界有没有缺失。移出对白的信息必须绑定实际可取得的字幕、对象或后续教学位置；“以后再讲”不算已交付。
- 当前行动：听者能否知道看哪里、用什么、做什么、先后怎样。严谨步骤和必要的“先/再”保留，不为了去模板破坏操作顺序。
- 评价：首答保存、答案揭示、知识帮助和独立应用条件保持。重写反馈不能提前说出未提交任务的答案，不能从一次点击推断理解。
- 分支：反馈说的内容确实由该分支的输入或条件支持；返回共同主线时保留对象、资料、帮助与草稿差异。没有语义评价能力的开放答案保留自评/人工审阅边界。
- 连续性：指代对象、画面动作、角色所知和过去/未来时态一致；不能把尚未发生的保存、修改或会师等事件说成已经完成。

缺少必要信息时补齐事实或讲解，再继续审语言。若影响已确认设计或小样，按原清单的受影响范围处理，不静默覆盖确认指纹。

## 5. 文字朗读自审与实际听审分开

先按当前动作逐段作文字朗读自审：是否能顺着说完，一遍听清主干；是否出现听者要回译的抽象搭配、指代跳变、术语连串、刻意抒情、句句设问和相同开头/收尾。改了段落就复读相邻段与实际分支接续。

Agent 仅依据文字检查时，写“文字朗读自审，未实际发声”。没有音频工具、录音或真人参与，不写成“已朗读/试听通过”。不把预计字速当作真实时长。

实际制作阶段使用同版最终文字和已选声线，连续听开场、术语/数字讲解、提问、误解反馈、帮助及返回，再逐句检查本次交付音频。试听检查绕口、歧义、错读、漏字、重复、停顿和句尾语气；声音自然和文字自然分别判断。不要靠放慢语速、背景音乐或“亲切自然”提示词掩盖书面台词。

按实际音频重新校准镜头、指向动作和字幕。供应方的单次字数上限属于技术分段条件，不改变写作句长；按完整句意拆分，不切断数字、术语和关键关系，不加空话凑回旧时长。

分别记录文字自审、TTS/录音听审、真人朗读、用户接受及未执行项。用户已表达的语气偏好继续生效，但对旧稿或参考声音的接受不能证明新稿已被接受；实际用户接受仍纳入原有设计/媒体门，不额外开第三道门。

## 6. 记录到既有 verification.md

逐场/分支登记台词标识集合、权威正文位置、触发条件、具体问题句、改写位置、事实/教学/时序核对和剩余问题。没有发现问题的段落也记录核对依据；不得用“已调用humanizer”“已去AI味”替代内容证据。

另外核对蓝图、媒体台词、字幕与权威正文的同版一致性。结构脚本只检查其已实现的字段、引用与流程条件；关键词没有命中不证明自然，词频或未校准 LLM 分数也不能作自然度准出依据。仍需引用文本作判断，并等待实际阶段的音频与用户反馈。

## 7. 方法维护时走读这些边界

修改本流程后，逐例说明采用了哪条规则、保留了什么，以及还需怎样核对。以下历史句子来自用户反馈，仅用于文体判定，不作为课程史实来源；候选表达不是用户已接受的稿，也不能成为各课固定台词。

| 标识与输入/上下文 | 应有的判断或候选行为 |
|---|---|
| `voice_map_metaphor`：“地图通常告诉我们经过了哪里，可这根从江西拉到陕北的线，解释不了中间这些折返。今天，我们给这张图补上原因。” | 删掉泛论与“补上原因”，保留起止位置、折返问题与接续。例如“这条路线从江西一直到陕北。你看这一段，走过去又折了回来。当时发生了什么？我们从出发那段看起。”路线指哪支部队仍按本课来源和上下文核对。 |
| `voice_base_nouns`：“根据地不只是地图上的地名，也关系到活动、组织和补给。” | 不反驳未提出的误解，给主体和动作。例如“红军在根据地组织队伍，也从这里获得补给。”若首次介绍，还须补足已核实的对象/名称；不因短了就判定完整。 |
| `voice_scope_deferral`：“中央红军后来到了陕北，其他各路红军的路线和结束时间也要分别看。” | 按当前用途交代为何先讲这一支；必需的各路路线/结束时间绑定后续实际教学，不把“稍后再看”当内容已覆盖。 |
| `voice_plain_teaching`：“分母表示把整体平均分成几份，分子表示取了其中几份。” | 作为简明解释可以保留；核对整体对象与等分示例是否已建立，不强加争执、悬念或动作。 |
| `voice_real_correction`：学生提交把分母当作取出份数的答案，老师说“这里的3是取了三份，不是把整体分成三份。” | 对实际误解的对照可保留；触发须来自已提交答案，不能仅因“不是”就删除。 |
| `voice_ordered_procedure`：“先断开电源，再检查接线。” | 顺序承担真实操作条件，保留“先/再”；来源与操作边界按本课核对，不能为去连接词调换顺序。 |
| `voice_precision`：“只有三条边都相等的三角形，才是等边三角形。” | 精确术语和限定可以保留；不能改成“三边差不多就行”，字数不作质量门槛。 |
| `voice_unread_answer`：只有自由文本保存成功，NPC说“你已经把每一段转向的原因都解释清楚了。” | 改成仅确认实际保存及可用自评/审阅动作；无语义审阅证据，不宣告解释正确或掌握。 |
| `voice_independent_hint`：独立题未提交，返场台词直接解释本题答案 | 保留任务条件，移到提交后或明确受助路径；口语自然也不能放行泄题。 |
| `voice_fake_casualness`：每段加“其实、说实话、你看”，另编讲解员童年经历 | 删掉机械口头语与无来源经历，按当下对象和关系重写；不将其当人物声音。 |
| `voice_branch_coverage`：开场已改，误解、帮助、恢复与结尾仍为旧套话 | 审阅未覆盖全范围；逐支提取并修订、核对触发与汇合，不允许只写开场通过。 |
| `voice_evidence_limit`：无音频、无真人，仅结构校验通过 | 只记录结构检查与有文本依据的自审；试听、真人朗读和用户接受均写未执行。 |

维护验收记录保留具体结果与限制，不能把这些例子的文字走读声称为真实学习者、真实录音或独立模型生成实验。
