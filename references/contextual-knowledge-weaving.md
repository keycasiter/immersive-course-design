# 语境知识编织

本文件是课程中**背景、人物、典故、事件、知识谱系、里程碑、影响与接受史**的唯一设计 owner。它回答的不是“再补多少资料”，而是：

> 学习对象处在怎样的知识世界中；哪些联系会改变学生对正文、现象、方法或作品的理解；这些联系应在何时出现，并怎样参与学生的判断与修订。

`knowledge-organization.md` 负责本课概念、程序和证据关系；`subject-pedagogy.md` 负责怎样教；本文件负责把核心内容放回其形成、流转和产生影响的脉络。背景不是独立章节，也不替代正文细读、实验、推理或创作。

## 1. 先建立语境图，再选择体验

对有历史、文化、人物、作品或学科发展脉络的内容，在写剧情、世界和媒体前扫描以下关系族：

| 关系族 | 要回答的问题 | 常见材料 |
|---|---|---|
| `origin` 形成条件 | 它在什么问题、环境、制度、技术或生活条件中出现？ | 创作处境、待解问题、社会环境、技术条件 |
| `people` 人物与位置 | 相关人物分别知道什么、追求什么、受什么限制？ | 作者、参与者、见证者、批评者、使用者 |
| `intertext` 典故与互文 | 哪些旧文本、概念、符号或传统改变了当前表达的含义？ | 原典、体裁惯例、引用、改写、象征传统 |
| `chronology` 事件链 | 哪些前因、转折和后果决定了当前对象的状态？ | 时间线、制度变化、实验序列、作品流转 |
| `lineage` 谱系与里程碑 | 它继承、反对或改变了什么，后来又被怎样发展？ | 前驱方案、关键转向、模型更替、风格流派 |
| `reception` 传播与解释 | 同一对象在不同受众、时期或场域中怎样被理解和使用？ | 评论、传播、教材化、争议、再创作 |
| `impact` 影响与边界 | 它改变了什么，又有哪些不能归因于它的结果？ | 方法影响、社会后果、技术应用、局限与代价 |
| `place` 地点与物质条件 | 地点、器物、媒介和尺度怎样约束所见、所做与所表达？ | 地理、建筑、材料、工具、传播媒介 |

先列候选联系，再选课程需要的**语境主干**。内容丰富的文学、历史、艺术、人物、理论或发明主题，至少比较四类关系，选出至少两条彼此相连、能回到核心材料的线索。短微课可以只采用一条主干，但必须说明它解决了哪一处理解困难。

选择依据是**解释力**，不是题目或正文中某个名词的表面联想。一个自然物、器物、地点或人物被写进课程，是因为它能解释语义、动机、条件、证据、转折、影响或认识边界；仅仅与正文出现同一个词，不构成主线。

## 2. 缺少背景输入时先做有限检索

当主题是具名作品、人物、事件、地点、理论、发明或里程碑，而用户只提供题目/正文，没有提供背景资料时，**资料缺失是检索任务，不是删除全部外部语境的理由**。除非用户明确禁止外部检索，首稿候选发散前完成一次有限、定向的语境检索。

按当前理解困难搜索，不做百科式搜集：

1. **核心原件**：权威原文、版本、作品/事件基本档案或原始记录；
2. **形成处境**：可信年谱、机构资料、学术/教育出版物或专业参考，定位人物、时间、地点、问题与媒介；
3. **关系候选**：只检索能解释当前词句、现象、方法或转折的典故、同时代材料、前驱方案或关键事件；
4. **接受与影响**：检索后来怎样解释、使用或改变它；影响主张同时找作用路径和边界；
5. **反证**：搜索一种可能削弱常见讲法、作者意图推断或单线因果的可靠材料。

来源优先级：

```text
原始文本/档案/数据
→ 官方机构、博物馆、专业学会、权威版本
→ 学术出版物、大学课程资源、可靠教育资料
→ 其他可追溯二手材料
```

搜索摘要、无出处转载和聚合页面只用于找到原来源，不能单独承载核心背景。每项进入主干的事实至少有一个可定位来源；存在争议或提出影响/因果时，比较两项独立来源或明确只作待核实候选。

创建精简的 `context_source_packet`，可写进 `course-design.md` 或配套来源表：

| 字段 | 内容 |
|---|---|
| `claim` | 拟使用的背景事实、关系或接受性概括 |
| `source` | 标题、机构/作者、URL/版本/页码及访问日期 |
| `evidence_status` | primary / authoritative_secondary / interpreted / disputed / unverified |
| `supports` | 它能支持哪项关系，不能支持什么 |
| `course_use` | 它将改变哪次重读、判断或迁移 |

停止条件：已经找到一条有来源、能回到核心材料并改变学生后续判断的语境链；继续检索只增加旁支，或超出课程容量。此时停止扩张，进入选择。若受限于网络、权限或时间仍未取得来源，保留候选和缺口，状态保持 `content_review_pending`；不能用纯文本内关系冒充已经完成外部语境编织。

## 3. 为每项背景分配教学工作

把选中的语境内容写入课程设计：

| 字段 | 必须写出的内容 |
|---|---|
| `context_item` | 具体事实、人物关系、典故、事件、里程碑或影响 |
| `source_and_status` | 来源位置；已证实、存在解释分歧或教学创作 |
| `relation_to_core` | 它与哪句原文、哪个现象、概念、程序或作品决定相连 |
| `learner_question` | 学生遇到什么真实疑问时需要它 |
| `teaching_job` | 它用于解释、对比、限定、因果、互文、迁移还是评价 |
| `reveal_moment` | 在学生作出哪次观察、预测或解释前后出现 |
| `learner_use` | 学生如何用它修改判断、补证据、重读、重做或创作 |
| `return_point` | 它之后在哪里再次影响行动或结论 |
| `removal_loss` | 删除后具体损失什么理解；无损失则删除 |

背景至少承担一种知识动作：

- 让学生重新解释正文或证据；
- 区分人物视角、时代条件和今日解释；
- 连接前因、转折、后果或模型变化；
- 比较继承、改写、反对和影响；
- 限定一个看似成立但过度的结论；
- 为新材料迁移提供可复用的关系，而不是可抄的答案。

只承担“增加氛围”“让内容更丰富”或“顺便知道”的资料不进入主链，可留作按需拓展。

## 4. 用问题触发背景，而不是先讲完背景

语境内容优先在学生遇到解释缺口时出现：

```text
先观察核心材料
→ 形成初步理解或真实疑问
→ 引入能改变解释的背景
→ 返回同一材料重读/重做
→ 将新关系用于后续判断
```

允许必要的入口定位，但开场不连续播放作者生平、年代、地点和成就。背景揭示应让学生能回答“我现在为什么需要知道它”，并在揭示后立刻使用。

可采用以下编织方式：

- **回返**：第一次读材料形成判断，获得背景后回到同一句、同一物或同一证据修订。
- **对照**：把同时代、前驱或后来版本并置，找出延续与变化。
- **因果链**：让条件、事件、选择和后果分时出现，学生补全但不能把时间先后直接当因果。
- **人物位置**：以信息、职责和限制区分人物，而不是把名人当讲解员。
- **谱系**：让旧方案、关键转向和当前形式共享一个问题，学生判断每次改变解决了什么、留下什么。
- **影响回声**：先完成核心理解，再观察它在后续作品、方法或社会实践中的可证影响与边界。

每条选中主干至少回返一次。背景只出现一次且不改变后续任务，说明它尚未被编织进课程。

## 5. 学科转译

### 语言、文学与外语

优先检查创作处境、体裁惯例、关键词历史语义、典故互文、作者在具体时刻的位置、同时代文本和后世接受。背景必须帮助重读词句、结构、声音或叙述视角；作者经历不能直接替代文本证据，也不能把一种解释写成作者唯一意图。

### 历史、地理与社会

把人物放进制度、利益、信息和时空条件；把事件放进前因、转折、并行过程和后果。里程碑不是孤立年份，影响需要来源、作用路径和边界；纪念叙事与历史证据分开。

### 数学、科学与医学

可使用问题起源、旧模型、关键实验、表征变化、技术条件和后续应用，帮助学生理解为什么需要某个概念或模型。避免“孤独天才突然发现”的英雄神话；人物故事必须回到证据、方法、模型或限制。

### 信息科技、工程与设计

围绕原始需求、前驱方案、失败约束、关键设计取舍、标准化节点及社会影响组织。版本史只有在它解释当前机制、权衡或风险时进入课程。

### 艺术与实践

连接媒介、材料、赞助/受众、风格谱系、技术条件、身体实践和接受变化。背景最终要改变学生的观看、聆听、动作控制或创作决策。

## 6. 事实、解释与创作边界

- 原文、年代、人物关系、事件、典故来源、科学史和影响主张需要可定位来源。
- 有争议的解释展示依据与适用范围，不用单一旁白消除分歧。
- 教学创作的人物、对白、档案、数据和场景明确标注，不嫁接成史实。
- “影响”必须有作用路径；同时出现、后来相似或广为人知不能直接证明影响。
- 背景不能替学生完成本应独立完成的来源判断、互文识别、因果解释或价值评价。

按“小心求证”集中维护来源与核验状态；课程正文保留学生当前需要的事实边界。

## 7. 深度审阅

设计审阅逐项检查：

1. **核心回返**：背景出现后，学生是否回到原文、现象、证据、程序或作品产生新的理解？
2. **连接成网**：人物、事件、典故、谱系和影响是否至少形成一条可解释的关系链，而非资料卡并列？
3. **跨时理解**：学生是否区分对象形成时、后来接受时和今天学习时的不同位置？
4. **行动使用**：学生是否使用背景作出解释、判断、修订或创作，而非只观看和记忆？
5. **解释力选择**：主线是否由理解困难决定，而非由标题中的高频名词决定？
6. **来源边界**：事实、争议解释和教学创作是否分开？
7. **删除测试**：删除某项背景后若核心理解和行动不变，则把它移出主链。
8. **容量控制**：背景是否挤压了正文细读、机制推理、独立任务和反馈修订？

以下任一情况保持 `content_review_pending`：

- 核心材料被压缩成引出背景的道具；
- 背景只在开场讲述，之后不再影响判断；
- 课程主线来自一个表面词语联想，不能解释作品或概念的关键关系；
- 人物、典故、事件或影响没有来源，或教学创作被当作事实；
- 学生只收集资料，未把它们用于重读、推理、修订或迁移；
- 为追求丰富度堆入大量人物和事件，导致独立表现无法完成。
- 具名作品、人物、事件、理论或发明缺少外部背景输入，Agent 未做定向检索就把所有形成处境、谱系和接受候选删除；

通过标准：未读设计说明的审阅者能指出一条“核心材料 → 语境揭示 → 学生重读/重做 → 后续判断”的完整链，并能说明删除其中任一选中背景会损失什么理解。
