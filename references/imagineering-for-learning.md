# Imagineering 思想的课程转译

路由：新沉浸课、情境与教学结合生硬的改稿，以及任何选择 `experience_design_mode=imagineering_only|project_extension|pbl_bounded|pbl_full` 的课程，先读取[内容设计质量与 Imagineering 路由](content-design-quality.md)。本文件提供公开 Imagineering 机制和边界，不拥有候选评分、内容质量状态或 PBL 字段。

用于新沉浸课、情境与教学结合生硬的改稿及方法维护。先读本参考，再选择叙事路线、写开场与节拍；在纲要、媒体、页面与验证材料中复用同一决定。不规定迪士尼画风、IP、事故开场、角色数量或技术栈，不新增交付物和人工确认门。

## 来源与适用边界

IM01—IM06 属于同一机构及合作课程的证据链，不能计作多份独立效果证据。部分课程视频页未成功取得正文，不把栏目标题或检索片段冒充完整教学内容。不引用未核对原文的“迪士尼十诫”版本作为官方硬性流程。

以下是本 Skill 的课程转译，并非迪士尼发布的学习科学标准。保留示范、练习、帮助撤除、独立迁移和效果评价；娱乐吸引力不能替代学科理解。

数学/科学与创作的结合同时参照[Pixar in a Box 的课程转译](pixar-in-a-box-for-learning.md)。公开 Imagineering 课程让学习者设计园区、体验与角色；不只在预定剧情里完成给定题。适合创作时，让学生决定希望受众体验到的效果，并用知识与测试修订方案。两套合作课程可借鉴共同机制，不互为教学认证，也不证明学习效果优于其他课型。

用户提供的“学习故事 + 工程 = 沉浸式学习体验”可作为本 Skill 的教学设计比喻，不标注为迪士尼官方公式。“记忆远强于纯听课”等效果比较没有本课对照证据，不写成事实或收益承诺。

## 用户补充原则的采用方式

先确定学习目标和证据，选择能承载它们的学习故事，再设计工具、空间和规则；已有方案可反复修订。技术服务故事，故事服务学习目标，不先造世界再寻找能塞入的知识点。

| 补充原则 | 在本 Skill 中怎样执行 | 保留的边界 |
|---|---|---|
| 故事先行 | 学习者先关注具体对象、愿望或问题，知识随后帮助理解与行动；后台设计先有目标与证据 | 不是所有课都禁止先讲概念，也不强制造世界观、危机与关卡 |
| 隐形教学 | 让问题、练习、判断与反馈嵌入当前事务，减少脱离对象的说教 | 隐去的是教案流程，必要概念、示范、推理与评价条件不能藏；体验后要能说出学到的关系并迁移 |
| 多层细节 | 同一对象提供基础理解、按需支持、进阶解释或创作空间 | 必需知识不藏在彩蛋，探索不成为通关配额，也不固定为三层 |
| 低成本魔法 | 选择能回答设计问题的纸面、声音、灯光、二维模型或空间布置 | 不用错觉代替科学事实、精确规则或正式媒体；成本降低不能削弱必需质量 |
| 跨工种共创 | 适合项目学习时围绕同一作品分工、交接、测试与迭代 | 团队生产、学生项目共创、单人自学分别设计；不默认给所有学生加岗位 |

## 1. 同时定义体验承诺与学习表现

在纲要写一句具体承诺：“学习者将亲自[看见/尝试/创造/解释什么]，通过[知识动作]使[对象/作品/解释]发生[可感知变化]。”另列独立表现成功标准，不用“惊叹、好玩、代入”替代。

判断兴趣来自现象本身、想做出的作品、人物关系、好奇缺口、条件取舍还是正在发生的事务。选择材料能支撑的来源，无须全部都有。可以公开说明主题与用途，禁止“绝不先讲目标”的新教条；人物无需朗读目标表。

体验承诺还须按[沉浸评价](immersion-evaluation.md)转成具体构念、声画/互动决定、材料定位与成立/矛盾判据；纯观看可承诺发现或连续观察，不强迫每段产生可控后果。预期体验、审阅判断和真实学生感受分别记录。

本 Skill 的沉浸式交互课堂固定采用 `video_led_web` 作为浏览器运行主线：视频事件承担上下文、节奏和连续性；互动、仿真、阅读和空间视图挂接到事件并返回。它不自动要求主引导 NPC、第一人称、分支剧情，也不要求学习者改变课程走向或提交持久证据。自定节奏探索、持续创作、长篇阅读和开放协作可以作为视频事件中的局部体验，只有无法合理挂接时才记录为范围边界。

## 2. 检查知识与事务的真实关系

每个核心任务写明：

`现实/学科目标 → 条件与未知 → 可用办法及限制 → 知识动作 → 可观察结果 → 下一步用途`

然后做反事实检查：

- **去掉知识**：能否靠乱点、照抄、目测或 NPC 代算得到同一结果？能则任务还不能证明目标能力。
- **允许其他办法**：卷尺、试装、查表、计算器、其他正确算法能否解决？能则承认，说明本方法用于制作前预测、比较多组条件、精确关系或一般规律。不能虚构工具失灵或专家无能来强迫指定方法。
- **去掉故事装饰**：对象的数量关系、证据或交流需求是否仍支撑任务？只剩“一道题解锁一道门”是奖励绑定，没有学科因果。
- **改变数据或选择**：对象结果与下一步是否依规则改变？只换夸奖文案是反馈缺口。

不要求证明方法在现实中唯一。需要证明它对本次理解、预测、制作或判断有明确价值，且学习者实际运用了它。区分现场测量、理想模型中的精确解与测量误差；生成画面不证明模型精确。

## 3. 环境分担信息，必要概念明确教

建立最小世界规则：对象用途、可变量、稳定限制、反馈来源，以及哪里是教学模型或创作。背景痕迹来自有意义的材料、使用中的物件、空间关系和人物行动，不写无关百科身世。

登记“对象线索 → 可读出的含义 → 首任务前的明确说明/等价路径”。旧尺寸标签可说明设计变化，不能单独解释首次出现的变量或单位。

- 能看懂的动作不逐句复述；符号、条件、来源和因果需要时明确教。
- 正常演示、安静观察、主动创作都可开场，异常不是必选项。
- 视觉简化、强迫透视、拟人化可服务氛围；测量、比例、历史和物理机制须有可信依据。
- 不假设学习者认识某 IP、职业习惯或地方生活，用当前输入补足。

## 4. 行动表达知识，反馈回应行动

逐交互写清“手/键盘做什么、头脑判断什么、对象改变什么”。拖动本身不是目标；拖动是否表达关系判断才是。只需观察时保留观察段，不强加拖拽、领取或开关。

低门槛首动作可以先发生，也可以接在必要示范后，不另造开场小游戏。它可产生有用观察记录或修订解释，无须操作重物、改变历史或承担专业施工责任。`first_consequential_action` 登记首次有意义参与的实际位置，前面的观察与示范不冒称已作答。

正确、错误、求助、修订依同一规则产生反馈。事务可以继续而能力仍需练习；共同主线只合并事件位置，不清除选择、对象和帮助记录，后续台词/对象层必须读取保留的差异。

角色有自己的事务与判断；一起观察、测试创作方案或帮助新手都可形成自然关系。不靠“专家不会这道题”解释学习者用途；等待时不循环催促、重复惊险或假倒计时。

## 5. 编排注意力、理解与节奏

逐 Beat 写“希望看哪里 → 看见什么 → 能理解什么 → 下一动作”。对象位置、人物视线、对比、运动和声音引导关注，也须有静音、键盘、低动态等价。

信息分成当前必需且明确呈现、可按需取得、后续才出现。线索可让人想继续，不能提前标出独立题答案或隐藏当前条件。阅读、计算、表达时停下冲突的对白与运动，允许思考、回看和修订。

新奇之后有理解和使用的空间，结尾回到承诺的对象或作品，看见判断带来的变化。不逐拍强造转折、奖励或情绪峰值，不统一秒数、镜头数和互动频率。

## 6. 创作与工程共同成立

先把设计意图、艺术判断、学科有效性与可实现条件分别写清。适合创作时，学习者至少拥有一项会改变结果的实质决定；范围可以很小，不规定逐场数量。多个满足条件的作品可以成立，审美偏好不能被数值正误覆盖。纯讲解、固定参数练习或史料解释可保留各自用途，不强加作品设计。

在原型中追踪“希望的效果→可控量→学科关系→测试结果→修订或有依据的保留”。测试可比较自己的两个版本，不强制真实观众或团队；模拟/NPC反馈按已知规则解释，不能冒称实测受众反应。纠正一道题与改进一个作品分别登记，不能用重复答到正确代替创作迭代。

世界规则在脚本、确定性模型、视频、页面与判定中一致。前台故事表现与后台实现分开；后台状态不用被角色念出，真实加载/失败不伪装成剧情异常。

媒体与页面计划写清主关注对象、数值/公式来源、生成画面职责、暂停等待、分支拼接、字幕安全区、输入等价、刷新恢复与资源故障。细节须有教学或具体体验作用；纯体验增量按内容质量 owner 取证，删除仅增加成本且分散注意的装饰。

视频主导网页课遵守两级资源准入：正式必需媒体失败时重试并阻止推进，保存恢复状态。无障碍等价不是故障的低配替代，也不强迫所有人体验同一运动与声音。Imagineering 的环境叙事、主动探索和多感官体验由视频主线加局部互动、仿真、阅读和空间视图共同承担；不要求学习者改变课程走向。

## 7. 原型回答疑问，证据分阶段成立

先核对概念—行动—结果，再选纸面走读、节拍板、确定性教具、animatic 或媒体闭环。每种原型只为明确问题服务，例如“新手是否知道水平距离与高度不同”“参数改变是否真的影响模型结果”。

- **设计自审**：移开作者解释，按实际台词、对象、控件走读；记录缺口，不冒充真实学习者。
- **结构与规则检查**：数学、引用、事件、状态、恢复、开放顺序；不能自动判定自然、好玩或理解。
- **媒体与运行验证**：实际检查视听、操作、错误/帮助/修订、等待与返回；无正式媒体不提前通过媒体门。
- **真实试学**：记录学习者想做什么、为何选某方法；区分知识困难、情境迷失和操作障碍，修订后再查。
- **独立评价**：在新材料与明确支持条件下评价。喜欢角色、观看完成、正确点击或受助成功不足以证明迁移。

小样优先覆盖最脆弱的结合点，不总挑最漂亮的开场。沿用设计与代表性媒体两道确认门；方法更新本身不需课程确认。

## 8. 分层探索与按需支持

在同一核心对象上按实际先修与表现安排深度：

- **共同主线**覆盖全部必需目标、关键证据、必要示范与独立应用；不把补救或必要资料藏起来让学生寻找。
- **按需支持**解决术语、操作或当前关系缺口，与进阶探索分开；接受帮助不使角色降级，也不自动降低目标标准。
- **可选进阶**可增加边界条件、证据矛盾、方法比较、结构剖析或新作品，不只是增加数字难度和阅读量。写清进入条件、学习增益、材料与反馈、返回状态；没有增益则不设。

不按年龄、看了多久、探索了多少彩蛋或“视觉型学习者”等标签判定水平。学习者可以选择深度，教学建议依据当前表现并允许再次求助；不必设固定层数或先得满分再打开拓展。

进阶不改变未参与者的必需目标与评价机会；不得提前泄露主线独立题答案。退出后保留对象与主线位置，不把自由探索改成永久资料面板。真实试学分别观察基础学生能否完成主线、进阶是否产生新解释、支持是否及时可见。

## 9. 低成本原型与可信体验

先说明每项纸板、声音、灯光、标识、布景或软件规则让学习者看见什么关系、做什么判断，再决定是否保留。“像神庙”“更有氛围”不能单独证明装置有教学价值。

原型用最低足够精度回答具体问题，例如纸面状态卡验证对话与交接、纸板模型验证空间操作、确定性二维仿真验证变量关系。保留原型用途和未验证部分，勿把早期走读当作正式媒体闭环验收。

区分表现技巧与学科机制：用灯光表现能量流可行，但方向与守恒仍由正确模型解释；用强迫透视吸引注意可行，但不能让学生据此测量真实长度。现场活动还须符合设备、材料与参与权限的实际条件。

正式方案可选择本来就足以达到目标的低成本媒体。用户已选视频主导网页时，纸板或静帧只验证前期问题，不擅自替代正式视频；正式必需资源失败也不因此降级推进。

## 10. 协作共创与项目式学习

先区分三种范围：

- **制作团队协作**：教学、叙事、美术、工程、声音与运行测试共同使用同一目标、世界规则和验收依据；是课程生产方法，不等于学生在做 PBL。
- **学生共创项目**：只有最终目标包含设计、制作、测试、协作或表达时，才让学生围绕一个有受众和约束的真实作品分工。编剧、工程、测试与讲解是可选功能，不是固定岗位或人数配额。
- **单人自学**：同一学习者可依次设计、验证、解释；NPC 可提供协作反馈，不据此称为真实团队协作。不能把课堂小组模式自动搬进视频自学课。

分工须写清“共同作品 → 本角色知识动作 → 给谁什么输出 → 接收方如何使用 → 整合与测试 → 修订”。各角色掌握本课程要求的共同概念；按需轮换、交叉检查或使用个体新任务，避免一人计算、其余只做布景。无合作目标时不强制轮岗。

团队成品、演示效果与每人的知识理解分别评价。展示时解释采用的原理、依据与限制，演示一次输入变化和对象回应；其他组或受众用具体问题反馈，再修订作品。口才、表演、制作资源不替代学科标准。

极简活动骨架按需填写在现有纲要和评价计划中，不新增固定七步或关卡数量：

`目标与证据 → 有受众的事务/作品 → 关系递进的体验路线 → 必要教学与工具 → 个人/分工行动 → 测试和修订 → 展示解释与新材料应用`

实际安排允许交错与回访。一段事件可整合多个知识关系，同一知识可在后续再次使用；拒绝“一关一知识点”造成概念割裂或无关谜题连锁。探险、历史时空、互动装置、企业工作站和语言小镇只是候选形态，需逐个证明知识如何改变其对象与结果。

## 11. 防止新套路的边界走读

以下为方法检验材料，不是已实施课程或效果数据。更新规则后逐例走读，记录触发规则与未验证项，不把预期写成真实用户结果。

| 输入 | 应产生的决定 | 应拒绝的输出 |
|---|---|---|
| 数学：弧线与水平线的交点 | 承认现场可测量；制作前预测或一般化须说明模型、变量、范围与收益；也允许纯数学探索 | “卷尺坏了所以必须解方程”、以生成画面认定比例、为练公式凭空换方程 |
| 科学：安静观察蒸发与凝结 | 从变化提出比较、预测；物理关系由证据/仿真解释 | 必须水管爆裂、会听指令的水被当作科学规律 |
| 历史：比较两份矛盾记录 | 环境定向、原文与来源支撑解释；改变学习者判断 | 解题改变史实、NPC 观点自动成为历史事实 |
| 语言：修改邀请函 | 收件人理解显露歧义，修订真实表达 | 单词答对只开门，信件不随表达改变 |
| 抽象概念：等式的不同变形 | 可明确讲解、示范、比较，再独立解释等价性 | 强造职业、穿越与首次搬道具 |
| 观察开场接必要示范 | 观察登记内容呈现，首次有意义参与在准备充分后，保留位置引用 | 以无意义点击凑字段或充当掌握 |
| 已选视频主线，分支汇合 | 回共同视频位置，同时保留对象变化和帮助状态 | 误称迪士尼要求自由漫游；回主线覆盖选择 |
| 静音、低动态或媒体失败 | 前两者保留同目标输入和行动；故障走重试/阻断、恢复 | 为沉浸隐藏字幕、强制运镜；静态占位冒充正式课 |
| 浮力情境：设计能承载给定负载的小筏 | 载荷、材料、模型与测试让排水/浮力关系有实际用途，按先修提供示范并解释测试 | 仅答对浮力定义后放行；强制荒岛逃生，未学也必须猜对 |
| 洞穴探险混合透镜、滑轮与水循环 | 只有整任务真需这些关系时组合；否则选一致的问题或分成不同课 | 按“每关一个考点”串联互不相关谜题 |
| 同一模型有主线、支持与结构拓展 | 主线完整；支持直接可达；进阶产生新解释且不泄露独立题 | 核心原理藏在隐藏热区；找到彩蛋才算学会 |
| 纸板和灯光验证机关方案 | 走读可检验叙事/空间，物理和规则另验，正式媒体验收另做 | 灯亮证明电路原理正确，纸面片段代替已选正式视频 |
| 学生分工编剧、制作、测试与讲解 | 输出被共同作品实际使用，关键概念人人有证据 | 编剧不学原理、工程组包办知识、只用团队演示给每人掌握结论 |
| 企业工作站方案或语言小镇 | 前者按真实需求权衡模型/显存/精度，后者以可理解沟通与回应检验表达 | 用“远强于听课”承诺效果；英语基础不足仍强制全英文无支持 |
| 同一弧线可选不同灯带高度 | 学生选效果，求解检验不同连接点，比较并解释修订；学科条件与偏好分评 | 所有参数固定仍称自由创作；把唯一审美答案当数学规则 |
| 动画表现重球或轻球 | 关键姿势/节奏决定表现，真实运动证据与艺术夸张分别解释 | 每种风格强制精确遵循真实运动；以挤压拉伸证明物理定律 |
| 仿真可直接显示交点或解 | 作为试验反馈，明确答案揭示时机；独立求解先提交且按条件换新材料 | 调滑杆抄出根就记独立掌握；为独立检查禁用所有正常工具 |

已有课程、媒体和确认记录不自动迁移；后续重做按授权范围应用并核对受影响内容。
