# 可覆盖的项目生产偏好

体验路线固定为本Skill的Three.js实时场景；这里提供工具/语言/声音偏好，不重定义体验语义或确认门。

| 项目 | 当前偏好与边界 |
|---|---|
| 语言 | 标准普通话，按实际学习者与材料可覆盖 |
| 声音 | 沿用已确认参考；已有项目排除Tingting正式配音。候选/参考见voice-catalog，当前环境未核对时不声称可生成 |
| 本地生成 | 已有Qwen3-TTS部署可在授权环境中复用；检查连接、权重、脚本、GPU占用与当前费用，不重复安装或假定私有主机可用 |
| 图片/纹理 | 需要时用当前可用的TRAE GenerateImage或Codex Image gen；提供方切换、成本与隐私依本次授权 |
| 几何与运行 | 程序化Three.js，精确版本由项目锁文件/当前安装确定；不强制GLB、Blender、前端框架或DCC环节 |
| 页面 | 按内容选择布局；可协同当前可用的UI设计/打磨Skill，缺工具时仍按页面契约落实，不强制额外安装 |

人物参考与旁白参考分开；同角色保持声线，实际听审另记。人物介绍时长按本课文字、出场和可读性决定，不写跨课固定秒数。工具探测仅在对应制作需要时执行；方法维护不实际调用生成服务。
