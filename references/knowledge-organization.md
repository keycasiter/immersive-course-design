# 知识组织与教学顺序

在写剧情和选媒体前执行本节。产出写进 `course-design.md` 的知识组织部分及蓝图的 `knowledge_organization`，不另造学习者必须浏览的知识点目录。依据与限制见[学习科学依据](learning-science-evidence.md)。

## 1. 拆出真正需要学习的关系

以原课、教材或权威资料为边界，列出完成目标所需的概念、事实、程序、判断条件及证据方法。知识单元可以合并，不按段落数、课时数或媒体数拆分。

每个单元填写：

- 稳定标识、具体内容、来源位置及对应目标。
- 哪些是已有基础，哪些在本课教；基础未知时如何诊断与支持。
- 学生必须建立哪种关系，在哪个教学场景建立。
- 易混淆概念、模型简化与适用边界。

用带理由的关系表组织它们：

| 关系 | 要回答的问题 | 顺序与检查的含义 |
|---|---|---|
| `prerequisite` 先修 | 不会 A 会具体妨碍 B 的哪步理解或操作？ | 先诊断、激活或教 A；不能以“通常先讲”代替理由 |
| `part_of` 部分与整体 | A 在哪个整体 B 中，承担什么作用？ | 来回联系局部与整体；不必把所有部分逐一讲完才看整体 |
| `causal` 因果或机制 | 哪个条件下 A 改变 B，通过什么机制？ | 比较条件与反事实；历史的多因、多时段关系不得压成唯一因果链 |
| `contrast` 对比 | A 与 B 的关键差异是什么，何时容易混淆？ | 提供能区分它们的例子及边界例；不能只给两个定义 |
| `representation` 表征 | A 与 B 如何表示同一对象或关系，有何损失？ | 明示对象、单位和关系的对应；会看动画不自动等于会解释图或公式 |

这些是本 Skill 的制作字段，不声称是学界统一的知识分类。概念间有联系不等于必有先修依赖；只对真正的先修关系检查无环。机制反馈可以成环，螺旋回访也可以多次出现。

## 2. 区分三种顺序

分别写知识依赖、教学顺序和叙事时间。它们可以不同：

- 教学可以先展示整体问题，再激活基础、解释局部，最后回到整体。
- 历史事件按史实发生，资料却可以按推理需要揭示；检查日期与统计口径。
- 机制动画遵循实际规则；教学可以暂停、切面、逆向查因，不能因此改写机制方向。
- 学习者可以自由取证，但必需关系须在共同任务中得到讲解、练习与独立检查。

每次进入下一段说明：已经建立哪种关系、还有什么缺口、下一任务为何此时合适。需要回访旧概念时说明此次新增了什么，避免换物件重做同一题。

已有知识可能帮助，也可能带来误解。入口诊断用于决定基础输入或示范，不依年龄、观看行为或一次选择推断能力。诊断不清楚时保留“不确定”，先提供不泄露独立题答案的基础支持。[LS1、LS4、LS7]

先修声明和课程定位分别成立。即使预计学习者熟悉基础，仍须在开篇说明本节主题、眼前对象和当前问题；诊断、父设计确认或已观看记录都不能代替必要介绍。是否继承上文按[开场引入](course-opening.md)核对实际入口和内容版本。

## 3. 按内容使用学科分析工具

| 内容特征 | 可采用的组织方式 | 需要防止的误用 |
|---|---|---|
| 概念与规则相互依赖 | 明示基础关系、规则条件与综合任务 | 把所有联系都画成先修链 |
| 多种解释或论证路径 | 比较来源、方法、主张与证据标准 | 因有多种解释而接受缺乏依据的答案 |
| 专业或实践任务 | 把概念、程序、情境判断与质量标准连起来 | 只教操作步骤，省掉何时用及为何用 |
| 情境案例承载抽象概念 | 在具体对象、概念关系与新案例之间往返 | 学生只记故事，未建立可复用关系 |

Bernstein 的“垂直话语／水平话语”与垂直话语内部的“层级／水平知识结构”是不同区分；不能把“水平结构”理解成没有先修、没有严谨标准。Hordern 对 Bernstein 与 Muller 的梳理可帮助检查概念连贯与实践连贯。[LS9]

上述是可选理论视角，不给整门学科贴永久标签，也不由学科名称决定唯一教学法。数学的教学依赖图不是 Bernstein 知识结构分类的同义词。

Maton 的语义波可用于检查是否从具体情境提炼关系、又把关系用于新情境；这是对理论的教学转化。语义重力与语义密度不是单一“难度轴”，不要求每场画波形或固定往返次数，也不据波形宣称学习有效。[LS10]

## 4. 写出整合与迁移

从目标反推一个或多个整合任务，让学生使用相关知识关系完成判断、解释或作品。单一目标的微课可以用其应用题承担整合；复杂课按实际目标组合，不强制一份长综合表。

教学中明确展示连接，再让学生自己完成连接。不要默认多个热点都点过就形成了知识网络。[LS1、LS4]

迁移设计写清保留的核心关系及改变的数据、表征、材料、条件或约束；按目标检查适用范围与不适用情况。远迁移需要另有任务证据，不能由同型练习或一道近迁移题推出。[LS1、LS8]

## 简短设计例

斜率课若目标是在带单位的图上解释平均变化率，可以组织“读取坐标与单位 → 求两点变化量 → 求比值并解释单位”；变化量之间的比值是关键关系，图、数据表和公式是表征关系。先检查坐标与差值基础，再用同一对象连接表征，最后换尺度或数据要求解释。先修依赖是为这个学习任务提出的设计判断，需在试学中核对。

工业革命课的事件时间线可以帮助定位材料，但“事件 A 早于 B”不能直接建立 `causal`。学生还需比较材料能支持什么、解释作用机制、考虑其他原因与时段限制。教学可先提出后果，再查此前证据，最后整合主张；叙事倒叙不改变史实发生顺序。

以上是方法示例，未替任何现有课程完成审校或试学，也不新增已确认教材范围。

## 交付前检查

1. 每个必需目标都有知识单元、来源、教学位置和练习／应用。
2. 先修缺口有实际诊断与基础支持；未确认基础明确标记。
3. 先修图无环；其他关系的环及叙事回访有解释。
4. 教学顺序依据知识关系和学习者条件，故事顺序没有遮掉必需概念。
5. 整合任务要求使用关系；学习者不能只靠收集、抄句或猜位置完成。
6. 未把任何理论名称或图的完整性当成理解证据。
