# 按学科与知识难点选择教学和体验

本文件拥有“知识难点 → 教学机制 → 表征 → 体验方式”的选择规则。新课、重大教学改稿、涉及教学方式的分镜生成或评审，先按[语境知识编织](contextual-knowledge-weaving.md)确定会改变核心理解的背景联系，再在固定剧情和媒体前读取本文件及下表中适用的知识类型。界面、输入、反馈实现仍由 [subject-interaction-guidance.md](subject-interaction-guidance.md)负责。

目标是让 Agent 对当前知识点作出有依据的鲜明设计。学科名只是检索入口：同属数学的数概念、协变和证明，需要不同体验；同属语文的意象、论证与语用，也不能统一成找线索或角色问答。

## 1. 按需路由

| 当前内容 | 读取指导 | 优先识别的认识难点 |
|---|---|---|
| 语文、文学、阅读、写作、外语 | [语言与文学](subject-pedagogy-language.md) | 声音与意义、叙述视角、篇章推理、形式与用途 |
| 数学、统计、概率 | [数学](subject-pedagogy-mathematics.md) | 单位、等价、协变、演绎、随机性 |
| 物理、化学、生物、医学机制 | [自然科学](subject-pedagogy-science.md) | 前概念、因果对照、多表征、尺度、系统反馈 |
| 历史、地理、公民与社会 | [历史地理与社会](subject-pedagogy-humanities.md) | 来源与立场、时空尺度、多因解释、价值和约束 |
| 信息科技、工程、艺术、音乐、体育与操作技能 | [系统、创作与动作](subject-pedagogy-practice.md) | 状态与过程、迭代约束、感知判断、身体控制 |

跨学科任务以独立学习证据确定主学科，其余指南只读取实际承担目标的部分。例如环境主题不自动要求读完科学、地理、工程三个指南；若只教地图尺度，主线按地理设计。

这些指南提供**有条件的优先候选**，不是每个知识点都有唯一最佳教法。表内声画和场景是作者的设计转译；来源支持范围见 §5。指南未覆盖的知识点按 §4 定点补全，再设计。

## 2. 先做知识点诊断，再发散内容候选

在 `course-design.md` 的“知识组织与教学选择”中，对每个核心目标写一段具体选择记录。紧密相关、采用相同机制的目标可以共用，但应逐项保留学习证据。

1. **连接语境与难点**：从已选语境主干回到核心材料，写清哪项背景联系会解决哪处理解困难；再定位知识点、学段、先修、要独立完成的动作，并提出一个能暴露当前误解的短任务。未实际诊断的误解记为设计假设，不能当作学生已经表现出的错误。
2. **比较教法**：从适用指南中比较至少两种认识机制，例如“面积分割”与“数轴单位迭代”，不是“城堡版”与“太空版”。分别说明能解决什么、可能强化什么误解，选定主方法。此比较并入已有内容候选，不额外生成一套候选表。
3. **确定表征桥梁**：选一种主表征和必要的辅助表征，写具体对应关系及转换动作。例如同一个量如何从实物变化映射到表格、图像或符号；颜色相同本身不算解释了映射。
4. **设计体验的关键时刻**：写出学习者预期、实际看见/听见的变化、需要重新理解之处；决定视角、尺度、声画节奏、注意对象和持续载体。可以是安静的辨听、突然显露的反例、内部过程展开或作品逐渐成形，不要求危机剧情。
5. **把教学做进体验**：示范一次判断过程；让学生有条件地尝试；反馈定位其具体关系或步骤；逐步撤去答案性支架。响应任务走两种合理输入，写清对象和后续状态差异。线性示范写观察任务和后续重建，不强加选择。
6. **换材料检验**：列出独立任务相对练习改变的关系、表征、条件或受众；写预期证据。学习证据与体验证据各一条：前者检验理解，后者检验注意、在场、情绪或行动感是否真实发生。

记录须有实际材料、动作和结果，不能只写“采用建构主义、探究式、具身认知、多模态”。优先保留能让目标关系变得可感知的设计；媒体复杂度在教学与体验价值明确后再优化。

## 3. 把体验强度写成可制作的决定

| 知识要求 | 可优先尝试的体验 | 具体设计问题 |
|---|---|---|
| 细微差异需要被注意 | 并置、重复、遮去答案标注、局部变式、声音对比 | 学生在第几次比较中能发现哪一差异？ |
| 过程或协变需要被理解 | 保持对象身份的连续变化、预测后揭示、同步读数 | 改哪一条件，哪个量随之变化，哪个保持不变？ |
| 看不见的结构需要解释 | 剖面、尺度切换、宏观与模型往返 | 切换前后如何确认仍是同一对象？模型解释哪一观察？ |
| 立场、意义或价值需要判断 | 不同声音、证据权限、真实受众、延迟出现的反证 | 哪一证据让原解释需要修订，而不是让角色宣布标准答案？ |
| 方法需要掌握 | 看得见的示范决策、可恢复的试做、局部慢放、撤架 | 学生接手的关键步骤是什么，帮助撤走后还能做什么？ |
| 作品需要形成 | 可比较版本、真实用途、局部改动、回应作品的受众 | 哪一修订产生了可见/可听差异，评价依据是什么？ |

体验允许鲜明的美感、空间感、好奇与情绪推进。为关键时刻留思考和感受的时间，不把每段声画切成测验。删减媒体时分别核对知识损失和体验损失：静态文字能复述同一事实，不代表能保留运动、节奏、空间或共同关注的作用。

## 4. 未覆盖知识点怎样扩展

按当前需要检索，不先收集百科式学科资料：

1. 核对用户指定地区、学段、教材版本的课程标准或教材材料，确定内容边界与先修；未指定且会影响方案时使用澄清规则。
2. 搜索该知识点的常见误解、教师教学指导、学科教育研究或经过观察的课堂案例。查询应具体到“知识点 + 年龄/学段 + 误解/表征/教学”，不要只搜“沉浸式课程最佳实践”。
3. 提取“针对谁、解决什么难点、采用何种材料和教学动作、什么条件有效”，与另一种方法比较。直接阅读实际来源再填写出处与支持范围。
4. 写入当前设计的选择记录，再推导体验。没有读到适用来源时，仍完成具体方案，将推测和待查项集中记入核验区；不捏造研究结论。

“扩展”默认写到当前课程资料中。只有用户授权维护 Skill 时，才把跨案例可复用的方法抽象回指南；不把新课人物、镜头或世界变成固定母版。

## 6. 完成判据

移去学科标签和作者的理论说明，仍能从实际任务识别该知识点的难点、所选教法、表征关系和体验作用；把它换成同学科另一个知识点时，核心动作或呈现机制应有必要变化。若只是换素材并保留“看视频—找线索—选答案”，回到 §2 重选。

语义审阅引用上述选择在实际材料、分镜和反馈中的位置；现有结构脚本只校验记录与契约，不判断教法优劣。真实体验和学习结果按 [immersion-evaluation.md](immersion-evaluation.md)及 [course-evaluation.md](course-evaluation.md)检验。
