# 课程设计颗粒度标准

本标准适用于新课、完整课程设计和重大教学改稿，必须执行。用户明确只要开场、某场或部分设计时，仅核对所选范围，并明确尚未设计的部分；不得把部分稿称为完整课程。

本文件本身是可移植的颗粒度基线，profile ID 为 `immersive_course_detail_v1`。历史项目样例只用于形成该基线，不是运行依赖，也不通过相对路径引用。采用以下从教学核心到完整课堂、资料、回应、迁移与验收的展开深度，不照搬题材、篇幅、模块顺序、人物数量、场景数或媒体类型。

## 一、完整设计的必写模块

模块可以合并或改名；每项内容必须实际存在，且在 `verification.md` 中指出位置。不能只用“按通用规则执行”填充。

| 模块 | 必须写出的实际内容 | 不足以交付的写法 |
|---|---|---|
| 教学核心、目标与边界 | 一句核心能力；各必需目标的可观察行为、成功标准、困难；先修、按需帮助、内容边界；来源版本、事实与情境创作的区别 | 只有知识点、目标名称或“理解某概念” |
| 语境知识主干 | 按 [contextual-knowledge-weaving.md](contextual-knowledge-weaving.md)列形成条件、人物位置、典故互文、事件链、谱系里程碑、接受与影响的候选；选中联系的来源、核心材料锚点、揭示时刻、学生使用、后续回返和删除损失 | 作者生平/时代背景资料卡；按题目中的名词联想场景；背景只在开场播放或只用于记忆题 |
| 知识组织与教学选择 | 知识单元、来源、先修及其他关系、入口诊断、整任务与顺序策略、教学顺序理由和整合任务；按 [subject-pedagogy.md](subject-pedagogy.md)写核心难点、至少两种教法的取舍、主辅表征映射与体验关键时刻；示范决策、指导与撤除、独立应用、表达反思、检索／间隔的选择条件及核对方式 | 理论名称、固定八步章节、章节列表、只换世界的候选或无理由的知识图 |
| 背景与自然开场 | 面向学习者的主题、用途与能力介绍；整体背景、对象/术语含义、已有认识、当前问题与角色关系；正文到呈现事件的绑定；各入口首任务前的衔接、独立小样背景和恢复 | 标题页、欢迎语、先修假设或直接派题；把隐藏后续路线误用为隐藏课程主题 |
| 全课持续事务与时间线 | 谁正在做什么；前一发现怎样引出下一问题；场景前后信息/状态；动线与时间口径；结课如何回收事务 | 依次讲知识、递新纸，未解释换资料的原因 |
| 人物与舞台连续性 | 身份、当前目标、可质疑判断或有用证据、回应方式；衣着、持物、位置、视点、光向；物件与媒体转换的连续性 | 人物只负责讲解、夸奖与催促 |
| 主线通用任务规则 | 当前动作何时开放；等待、求助、重试与继续；首答和修订；操作帮助与知识帮助；确定规则与开放解释的判定边界 | 只有“互动”“可求助”“自动评分” |
| 完整场景与教学资料 | 所有必需场景按第二节展开；实际资料全文、准确数值/单位/条件、来源；哪些信息先不显示，学生怎样取得，必要讲解何时接上 | 只有资料名称、摘要、镜头主题或提示词 |
| 回应、补救与再做 | 每个核心任务的成立要点；主要误解逐项对应台词/知识音频、定位动作、学生修订、返回与接续；求助分层的实际内容 | “正确就继续，错误则提示”；所有选项同一回答 |
| 新材料独立应用与再查 | 完整新材料与题干；相对练习改变了什么；按目标的结果/依据/范围；首答保存与反馈时机；受助后再查的实际新材料和规则 | 只说“换一道题”“后续独立应用”；答案先泄露 |
| 结课与学习记录 | 人物/事务怎样收尾；学习者看自己的作品、判断与变化；完成与理解分开；按需回到原对象查看或修订；内部保留首答、帮助、待审和评价来源 | 播完即学会、只给总分/奖杯，或常驻展示后台评价状态 |
| 目标映射与评价 | 来源→目标→教学→练习→反馈/补救→新材料；逐项互动价值；设计评审、真实试学和效果评价的方法与当前状态 | 点击量、结构通过、满意度代替学习证据 |
| 形成性闭环与量规 | 实际表现、解释及替代原因、具体教学动作、实际再查任务；量规维度／表现例子、允许资料与帮助条件、审阅边界 | 正误加通用评语；用关键词、文长或一次结果直接判掌握 |
| 制作与体验验收 | 素材与场景/分支对应；实际对白及音频验收方案；精确教具规则；媒体切换、恢复、无障碍、窄屏；优先小样的完整链路与通过条件 | “后续生成视频”“UI再优化”；把计划当成已实现 |

无法适用的媒体或可选模块写明原因和教学等价路径。不因参考课有全景就强加全景，也不为了凑模块制造无关情节。

## 二、每个必需场景都写到这个程度

1. **进入与退出状态。** 指明来源、目标、前置资料或结论；人物当前要办什么、哪里仍不清楚、这一场完成后得到什么。下一场由哪个动作、判断或新资料自然引出。
2. **可拍摄的过程。** 按实际事件拆镜头或连续段落，写起止画面、景别、视点、人物位置/目光/持物、动作、镜头运动和转场。时长是待录音与小样校准的估计，不含学生思考等待；不编造已制作热区坐标。
3. **可录制的声音。** 写完整对白、必要知识讲解、主要反馈与提示，不用“解释公式”“说明影响”代替正文。标明谁说、何时停、画面哪个对象与话对应。按[可录制台词与口语审阅](spoken-language-and-review.md)确定听者当前所知及说话用途，逐段赋稳定台词标识，复查全部主线/分支；整段改写后保留事实、必要教学和反馈时机。来源和制作声明集中放资料入口，具体知识边界仍须讲准确。
4. **真正可用的材料。** 文书给全文或明确引用的原文；数学给点、数值、单位、轴、条件与精确图形规则；机制给结构与状态规则；语言/技能给实际交流对象、语境或作品。课堂不能依赖后续制作者临时发明必需证据。
5. **信息与动作顺序。** 写哪些内容先可见，哪个观察、点选、测量、预测或提问取得新信息，何时插入必要讲解。每次只开放当前需要的动作；可自由取证时写清共同返回点和未看材料的取得方式。
   同时说明本场属于完整任务呈现、示范、引导练习、独立应用或表达反思中的哪一项；可合并，不为凑环节新增页面。
6. **完整互动。** 每个核心或取证任务给稳定标识、教学作用、触发事件、前置、画中对象、开放/遮挡/等待条件、同场景展示、实际题干、学生操作、成立要点、证据和删减损失。辅助入口说明仅支持理解或操作，不计掌握。
7. **具体分支。** 至少分别覆盖结果成立、主要错误/解释缺口、求助。每支写实际台词或知识音频、角色/资料/模型的变化、学生下一步，以及回到哪个对象/镜头。按可核对的答案类型触发；自由解释待审阅时不能让角色假装已理解全文。
8. **补救后的实际再做。** 写提示各层定位什么、示范什么；学生自己修订哪一项、何时保存；仍不确定怎样继续。不能自动填好答案后记为掌握，不以重复点选掩盖首答错误。
9. **接续与记录。** 写完成条件、交回物件或现场接续动作；进入/退出局部的视点、时间、声音；保存首答、帮助、修订、媒体/任务阶段。回看和恢复不得跳过当前待做动作或提前揭示未来资料。

无作答的教学段不必虚构正误分支，但必须写出实际教学内容、学生观察对象、呈现依据及进入下一动作的条件。共用规则可集中写一次，单场仍要填写它特有的资料、内容、变化和接续。开场和结课按其功能展开，不机械套测验。

## 三、设计细致，学生仍可轻量参与

- 优先安排“人物提出当前问题 → 学生观察/选择/测量 → 取得证据 → 必要讲解或回应 → 再判断/修订 → 场景继续”。可按学科调整，不能所有任务都默认“完整讲解视频结束后填一整张表”。
- 同一个物件可以承接多次小动作。写清每次开放的输入和信息；不为了写细而增加章节、题卡和必点热点。
- 早期判断允许“不确定”，不要求猜对未教内容。少量点选或短计算可以承担局部思考；综合解释与独立应用保留真正的依据和推理要求。
- 分支可以汇合，但选择须改变当前回应、观察先后、资料组织或对象状态，并具体影响后续检查。仅更换按钮颜色、通用评语或重新播放同一片段不满足这一项。
- 讲解仍需充分。轻量操作不意味着省掉概念、必要示范、数学计算或证据解释；示范要展示过程、理由、条件与自检，不只播放正确结果。制作细节充分也不能证明学生已经学习。

## 四、独立应用与再查必须可直接使用

按必需目标给出新的数据、对象、约束或材料。仅改姓名、场景名或按钮顺序不足以检验迁移。材料既能支撑合理结论，也可有明确的信息不足；把范围与不足判断写进评价要点。

同一能力或目标之间存在泄露风险时，在相关首答都保存前，不显示答案、正误、解法高亮或角色评价。可以逐次填写、切换修订，统一提交不等于同时显示长表单。一般资料重读、原文朗读与操作说明可提供；知识帮助与旧答案回看按实际泄露范围记录受助。

结课后对仍需帮助的目标设计新材料再查，写出实际材料、题干与评价要点，不只承诺以后再出题。只对需要再查的范围安排，不强求每门课固定两个整包。再查结果单独记录为接触过反馈后的新材料表现，不追认原首答。

## 五、交付前的实际核对

使用 `assets/verification.template.md` 生成本版 `verification.md`：

1. 对第一节各模块注明主文档或配套文件的具体章节/锚点，并写核对结论。
2. 列出所有必需场景与必要分支，核对实际材料、真实台词、学生行动、结果与回应、补救再做、接续和记录；不能只抽查开场。
3. 核对设计、媒体计划、评价方案和蓝图中的标识、数据、单位、条件、答案与路径是否一致。
4. 记录结构脚本和内容自审的实际结果。媒体、浏览器、人工确认和真实试学未执行时明确写“未执行”。
5. 缺少必需教学内容或留有模板占位时，先修订再交付完整设计。未知的工具能力、后续待做的素材可以保留为待验证；两者不得混淆。
6. 在可录制台词审阅表核对全范围台词标识、权威正文、实际问题/改写与事实/教学/触发不变量，覆盖反馈、帮助、恢复和结尾。文字朗读自审、实际听审、真人朗读和用户接受分开写；不能用结构通过或“已去AI味”代替内容证据。

完成的判断是：制作或实现者能依据本版完成课堂，不需要自行补写必需资料、题干、教学台词或反馈逻辑。文档长度、场景数量、表格数量和蓝图通过不能单独满足该判断。
