# 课程页面结构

先按[课程成品UI与布局](final-page-ui-quality.md)建立 `page-design.md`，用项目配置指定的界面能力和随 Skill 的 HTML/CSS 模板实现。video_led_web 使用专属轻量骨架 `assets/video-led-course-page.template.html` 和 `assets/video-led-course-page.css`；通用 `course-page.template.html` 的大面板样式不适用于该配置。当前工作区默认使用 UICraft。实际布局由本课对象、资料和学习动作决定。

## 视频主导网页模式的视觉覆盖规则

当本课配置为 `video_led_web`，必须优先遵循[视频舞台契约](video-surface-contract.md)、[视频主导网页课程配置](video-led-web-course.md)和[参与表面枚举](scene-participation-design.md)：运行时区域只作为语义/兼容结构。`scene-media` 铺满唯一舞台；直接控件、阅读、实验或深层视图按参与计划进入并返回原事件。`.task-surface` 默认有界短判断/帮助；`data-surface="reading"` 可承载当前判断所需的阅读与理由，长材料另设按需深层视图。进入课程后仅按需显示控制与导航。

任何三栏课程壳、常驻侧栏、常驻证据/进度卡、固定课程目录、结果面板或页脚都属于普通交互课程结构，不能包裹 `video_led_web`。如果页面需要这些区域才能解释或导航课程，应先重新评估体验配置，不得继续标记为视频主导网页。

## 固定运行时区域

下列区域和其后的通用卡面、间距、工具栏、入口、文书与工作面规则适用于常规交互课程。`video_led_web` 只继承必要的语义标识与可访问性要求；任何与上面的“视频主导网页模式”相冲突的视觉呈现均不适用。


`main#course-stage` 是唯一根舞台。下列9个区域各有唯一标识，并且是根舞台的直接子节点；CSS位置、尺寸与排列不由区域名锁定。

| 区域 | 标识 | 内容与布局基线 |
|---|---|---|
| 主媒体 | `scene-media` | 视频、全景、3D或确定性教具，按当前任务切换 |
| 场景遮罩 | `scene-shade` | 按需要提高文字/操作可读性，装饰层不接受操作 |
| 工具 | `course-header` | 课程名、当前地点与暂停、声音、全屏；按屏宽排列 |
| 开场 | `course-entry` | 短背景、课程名、当前问题、开始；有记录时继续优先 |
| 对象入口 | `scene-objects` | 画面中的当前对象按钮 |
| 字幕 | `course-caption` | 清晰安全区，通常在底部；角色对白按需显示角色名，旁白只显示正文 |
| 当前动作 | `course-actions` | 一个主动作，必要时一个辅助入口；位置随当前对象和设备调整 |
| 工作面 | `task-layer` | 一次一个阅读、操作、判断或反馈层 |
| 临时状态 | `course-status` | 当前加载、保存或重试信息 |

工作面保留一个 `.task-surface`，内部固定为 `.task-header`、`.task-body`、`.task-footer`。顶部给对象名和返回动作，正文显示当前资料或问题，底部保留提交与必要辅助动作。长内容在正文滚动；同一任务的原文、教具、批注和作品可在正文内并列或顺序排列。必要二维教具可在自身容器缩放/滚动，不使周围正文横向溢出。

打开工作面时隐藏背景热区、字幕和同义前进入口，暂停主线媒体。关闭后恢复原场景、视角、时间和已填内容；焦点回到入口。Escape 返回，Tab 留在当前层。顶部媒体工具可见，但弹层打开时键盘焦点留在工作面。

隐藏热区和重复字幕不等于移除现场角色。工作面中发生角色回应或引导时，保留同场角色实体及与对象相关的参与，或用明确衔接的角色近景后返回。按[媒体、角色与互动连续性](media-interaction-continuity.md)调整构图，桌面和手机都不能只剩姓名与真空对白；全景转身后可定位角色，媒体切换保留空间锚点、对象和任务状态。

## 按状态呈现

| 状态 | 当前内容 | 主动作 |
|---|---|---|
| 开场 | 背景和具体问题 | 开始／继续 |
| 视频 | 当前事件和字幕 | 播放控制 |
| 探索 | 当前问题和对象 | 查看／询问／操作 |
| 阅读 | 一份资料及必要对照 | 回到现场／作出判断 |
| 判断 | 当前问题、选项或输入 | 提交 |
| 反馈 | 对应回答的结果、线索与回应 | 修订／继续 |
| 结课 | 作品和本课记录 | 下载／回看 |

一次围绕一个判断开放操作。必要的证据和简短理由可以同屏；整合解释在需要时出现。后续节点由事件开放，完成后再提供节点回顾。

选取物件或原句后，在当前文书留下可撤回的记录；多条依据以最近一条和按需展开控制阅读量。现场短回应贴近实体人物，不能遮挡面孔、正文或底部动作，不提前判正误。替换局部DOM后保持正文位置，并恢复到原句、可用控件或当前问题的焦点。实现前按[前端与原型设计契约](frontend-prototype-contract.md)固定组件和状态。

## 字幕

旁白字幕只显示正文，不加人名、“旁白”“知识旁白”或音色编号。角色对白按需显示角色名。

按台词类型控制 `.speaker`：旁白隐藏并清空姓名行，角色对白填入对应角色名。切换时同步更新，隐藏姓名行后不留空白。旁白不触发人物首次出场介绍。

## 人物首次出场

制作与验收读取[人物参考与首次出场](character-reference-and-introduction.md)。姓名和当时身份烘焙进实际视频，字幕关闭仍可见；网页附加锚点是增强。页面完整呈现媒体安全区，随播放/暂停/跳转自然呈现成片介绍。人物来源、时长、出镜与本版审阅只在该 owner 维护。

## 样式基线

复制 `assets/course-page.template.html` 和 `assets/course-page.css`。保留区域标识与结构，填入课程内容和事件逻辑。

| 项目 | 基线 |
|---|---|
| 桌面边距 | 顶部32px，工作面24px |
| 工作面 | 最大宽860px，距顶部92px，正文内边距32px |
| 手机 | 640px以下单列，工作面外边距12px、正文20px |
| 正文 | 18—19px，行高1.7—1.9 |
| 问题 | 桌面32px，手机25px |
| 字幕 | 桌面18px，手机17px |
| 操作文字 | 14—16px，点击区至少44px高 |
| 间距与圆角 | 8px倍数，圆角4px |
| 颜色 | 深色现场、浅色工作面、一种主动作色 |

表内值是起始样式，不是全部课型的固定尺寸。保留区域标识、返回/恢复和主次动作语义；按[内容布局变体](final-page-ui-quality.md)调整网格、对齐、比例、工作面宽度、资料载体、字体与主题。关键图表和推理对象完整呈现，不能用缩小文字或裁掉依据维持旧版式。媒体、局部模型和实际反馈按课程设计接入。

## 页面文字

正文保留剧情、知识、证据、题干和反馈。界面文字只说明当前对象、动作和结果。

| 用途 | 写法 |
|---|---|
| 入口 | 查看收货单 |
| 判断 | 煤怎样支持这家厂生产？ |
| 返回 | 回到院落 |
| 错误反馈 | 收货单写着“锅炉燃料”。再查煤的用途。 |
| 状态 | 正在加载模型／记录已保存／画面未加载，重试 |

删除重复标题、操作解释、泛化鼓励和防御性补充。按钮明确时省去说明段。模型、Skill、实现过程、验收口径和“完成不等于学会”等制作说明放在文档，学习记录中直接显示实际结果。

内部契约中的“核查、验证、证据、待审、首答、修订、目标状态、完成条件”等词不直接作为学习者进度、按钮或NPC台词。按 `experience-framing-and-learner-language.md` 改成当前对象、动作、可见后果和自然接续；例如内部 `pending_review` 可以不显示，或由NPC说“我还没看到你为什么选这段”，不能显示“待核查/继续核查”。只有这些词是学科概念或真实职业动作时才自然使用，也不能把系统状态伪装成剧情。

## 交付

样式参考为 `course-page-style-v0.1/index.html`，含开场、现场、文书、判断、错误修订和返回。正式页面复用语义结构，接入本课媒体、任务与声音，并交付本版 `page-design.md` 和实际审阅记录。

生成后运行结构检查，修正区域、工作面或共用样式的缺失：

```bash
python3 "<skill-root>/scripts/validate_page_structure.py" "<course-directory>/index.html"
```

在已授权的浏览器验收范围内，桌面1440×900、手机390×844各检查：当前内容、单一主动作、无遮挡、正文无横向溢出、工作面返回、键盘操作、声音暂停、刷新继续。再按成品UI模块检查长内容、缩放、横屏和正式媒体安全区。验收结果写入 `verification.md`。

Prototype Craft 的静态结束条件只适用于子工具阶段；返回后由课程编排器继续已授权的启动、操作和验收。只交付静态示意时按范围记录未执行项，旧结果不能替代本次实测。组件应用按[运行DOM与采集证据](frontend-prototype-contract.md)校验，源HTML壳不当作运行页面。
